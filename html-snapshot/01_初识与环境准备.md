常见问题及解决方案</h4> <br><h5 <code>python</code> 提示“不是内部或外部命令”</h5> <br><ul><li><strong>原因</strong>：未将 Python 添加到系统环境变量 Path 中。</li><li><strong>解决方案</strong>： <br>  <ol><li> <p>重新安装 Python，勾选 “Add python.exe to PATH”。</p> </li><li> <p>手动配置环境变量：</p> <br>    <ul><li>右键“此电脑” → 属性 → 高级系统设置 → 环境变量。</li><li>或手动配置环境变量：右键“此电脑” → 属性 → 高级系统设置 → 环境变量，在 Path 中添加 Python 安装目录及`Scripts` 目录（如`D:\develop\python\` <br><ul><li><strong>原因</strong>：Windows 系统的“应用执行别名”干扰。</li><li><strong>解决方案</strong>： <br>  <ul><li>设置 → 应用 → 高级应用设置 → 应用执行别名 → 关闭python.exe 和python3.exe 的别名；或使用完整路径运行 Python。</li></ul> </li></ul> <br><ul><li><strong>作用</strong>：告诉操作系统，在命令行输入命令时应到哪些目录中查找对应的可执行程序。</li><li><strong>工作流程</strong>： <br>  <ol><li>用户输入命令；</li><li>系统先判断是否为内部命令；</li><li>若不是，则依次到 Path 指定的目录中查找；</li><li>找到则执行，找不到则报错：“不是内部或外部命令，也不是可运行的程序或批处理文件。”</li></ol> </li><li><strong>用户变量 vs 系统变量</strong>： <br>  <ul><li><strong>用户变量</strong>：仅对当前登录用户有效。</li><li><strong>系统变量</strong>：对所有用户有效。</li></ul> </li></ul> <br><h3 id="%E4%B8%89%E3%80%81Python%20%E5%BC%80%E5%8F%91%E5%B7%A5%E5%85%B7" name="3.1%20%E5%B8%B8%E8%A7%81%E5%BC%80%E5%8F%91%E5%B7%A5%E5%85%B7">3.1 常见开发工具</h4> <br><ul><li><strong>VSCode</strong>：轻量级编辑器，插件生态丰富，支持多种语言。</li><li><strong>PyCharm</strong>：JetBrains 公司出品的专业 Python IDE，Python 开发中使用最广泛。</li></ul> <br><h4 id="3.2%20%E8%84%B1%E7%A6%BB%E5%BC%80%E5%8F%91%E5%B7%A5%E5%85%B7%E8%BF%90%E8%A1%8C%20Python%EF%BC%88%E5%8F%A4%E6%B3%95%E7%BC%96%E7%A8%8B%EF%BC%89" name="3.2%20%E8%84%B1%E7%A6%BB%E5%BC%80%E5%8F%91%E5%B7%A5%E5%85%B7%E8%BF%90%E8%A1%8C%20Python%EF%BC%88%E5%8F%A4%E6%B3%95%E7%BC%96%E7%A8%8B%EF%BC%89">3.2 脱离开发工具运行 Python（古法编程）</h4> <br><p>只用解释器也能运行 Python，过程如下：</p> <br><ol><li><strong>交互模式</strong>：在 cmd 中输入 <code>python</code> 进入 <code>>>></code> 环境，但每次只能执行<strong>一行</strong>代码，编写多行程序很不方便。</li><li><strong>脚本文件</strong>：Python 是<strong>脚本语言</strong>，代码可以写在文本文件中，由解释器从上到下逐行执行——用记事本写好多行代码，把后缀名改为 <code>.py</code> 即可。</li><li><strong>运行脚本</strong>：在 cmd 中执行 <code>python 文件名.py</code>。若提示找不到文件，有两种解决方法： <br>  <ul><li><strong>方法一</strong>：用 <code>cd</code> 命令切换到文件所在目录后再运行。</li><li><strong>方法二</strong>：在文件资源管理器中打开文件所在文件夹，在地址栏输入 <code>cmd</code> 回车，可直接在该目录下打开命令提示符。</li></ul> </li><li><strong>显示文件扩展名</strong>：系统默认隐藏扩展名，需在资源管理器中勾选“查看 → 显示 → 文件扩展名”，才能确认后缀已改为 <code>.py</code>。</li><li><strong>查看系统类型</strong>：设置 → 系统 → 系统信息 → 系统类型（如 64 位操作系统），用于选择匹配的安装包。</li></ol> <br><p><strong>结论</strong>：以上方式都只依赖解释器，缺少代码提示、错误提示、一键运行等功能，因此实际开发中引入<strong>开发工具（IDE）</strong>。</p> <br><h4 id="3.3%20PyCharm%20%E7%AE%80%E4%BB%8B%E4%B8%8E%E4%B8%8B%E8%BD%BD" IDE you need" rel="nofollow">PyCharm: The only Python IDE you need</a></li><li><strong>下载</strong>：选择 Windows 版本，下载 <code>.exe</code> 安装包。</li></ul> <br><h4 id="3.4%20PyCharm%20%E5%9F%BA%E6%9C%AC%E9%85%8D%E7%BD%AE" name="3.4%20PyCharm%20%E5%9F%BA%E6%9C%AC%E9%85%8D%E7%BD%AE">3.4 PyCharm 基本配置</h4> <br><ul><li><strong>主题颜色</strong>：设置 → 外观与行为 → 外观 → id="4.1%20%E5%88%9B%E5%BB%BA%E9%A1%B9%E7%9B%AE%E4%B8%8E%E6%96%87%E4%BB%B6" name="4.1%20%E5%88%9B%E5%BB%BA%E9%A1%B9%E7%9B%AE%E4%B8%8E%E6%96%87%E4%BB%B6">4.1 创建项目与文件</h4> <br><ol><li>打开 PyCharm，点击“新建项目”。</li><li>设置项目位置（无中文、无空格路径）和项目名称。</li><li>选择解释器类型：项目 venv（虚拟环境），基础解释器选择已安装的 Python。</li><li>点击“创建”。</li><li>在项目中右键 → New → Python File，命名为 <code>01. 快速入门.py</code>。</li></ol> <br><h4 使用<strong>换行</strong>作为语句结束标志，一行写一条语句；也可用分号`;` 分隔多条语句（不推荐）；</li><li>源文件后缀名为`.py` 。</li></ul> <br><blockquote> <br> <p>技巧（输入法标点设置） ：在中文输入法中开启“<strong>中文状态下使用英文标点</strong>”，避免反复切换。</p> <br> <br><ul><li><strong>作用</strong>：对代码进行解释说明，供开发人员阅读，Python 解释器会忽略注释内容。</li><li><strong>单行注释</strong>：以 <code>#</code> 开头。 <pre><code class="language-python"># 这是一个单行注释<br>print("Hello")<br></code></pre> 主题。</li><li><strong>字体</strong>：设置 → 编辑器 → 字体 → 字体、大小、行高。</li><li><strong>编码</strong>：确保文件编码为 UTF-8。</li></ul> <br><h3 id="%E4%BA%94%E3%80%81%E5%B0%8F%E7%BB%93%E4%B8%8E%E7%BB%83%E4%B9%A0"
