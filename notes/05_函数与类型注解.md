<br><ul><li><code>input()</code>、<code>print()</code>、<code>max()</code>、<code>min()</code>、<code>len()</code>、<code>sum()</code> 等都是 Python <br><p><strong>语法格式</strong>：</p> <br><pre><code class="language-python"># 定义函数<br>def 函数名(参数列表):<br>    函数体<br>    ......<br>    return 返回值<br># 调用函数<br>函数名(参数)</code></pre> <br><blockquote> <br> <p><strong>形参和实参是什么关系？</strong></p> <br> <p>形参是定义时起的"<strong>占位变量名</strong>"，实参是调用时给出的"<strong>具体值</strong>"。调用时，实参的值会按位置（或按关键字）一一赋给形参——相当于执行了一次 <code>形参 = 实参</code> 的赋值。例如 <code>rectangle_area(20, 10)</code>：<code>l = 20</code>、<code>w = 10</code>，函数体内用的是 l 和 w，而它们拿到的正是调用时传的 20 和 10。</p> <br></blockquote> <br><blockquote> <br> <p><strong>注意</strong>：函数定义时有多个参数，参数之间用逗号 <br><p><strong>小结</strong>：</p> <br><ol><li> <p>有参数有返回值的函数：</p> <pre><code class="language-python">def rectangle_area(l, w):<br>    return l * w<br>r_area = rectangle_area(20, <br><p><strong>嵌套调用</strong>：在一个函数中，又调用了另外一个函数。</p> <br><p><strong>函数调用遵循栈结构</strong>：每调用一个函数，就把一层"调用记录"压入调用栈；函数执行完毕，就弹出这一层（出栈），回到调用它的地方继续执行。最后被调用的函数最先返回（<strong>LIFO：Last In First Out，后进先出</strong>）。</p> <br><blockquote> <br> <p><strong>结合示例理解出栈顺序</strong></p> <br> <p><code>function_a()</code> 先压栈</p> <br> <p>→ 执行到 <code>function_b()</code> 时 b 压栈</p> <br> <p>→ b 执行到 <code>function_c()</code> 时 c 压栈</p> <br> <p>→ c 打印完 <code>"c ..."</code> 就执行完了，<strong>c 最先出栈</strong></p> <br> <p>→ 回到 b，继续执行 b 里剩下的 <code>print("b ... after")</code>，b 执行完毕出栈</p> <br> <p>→ 回到 a，执行 <code>print("a ... after")</code>，a 最后出栈。</p> <br> <p>就像子弹弹夹：<strong>最后压进去的子弹最先打出来</strong>（后进先出）。</p> <br></blockquote> <br><p><strong>代码示例</strong>：</p> <br><pre><code class="language-python">def function_a():<br>    print("a ... before")<br>    function_b()<br>    print("a ... after")<br>def function_b():<br>print("b ... before")<br>function_c()<br>print("b ... after")<br>def function_c():<br>print("c ...")<br>function_a()</code></pre> <br><p><strong>执行流程</strong>：</p> <br><pre><code class="language-python">function_a() 开始（a 压栈）<br>    ├── 打印 "a ... before"<br>    ├── 调用 function_b()（b 压栈）<br>    │       ├── 打印 "b ... before"<br>    │       ├── 调用 function_c()（c 压栈）<br>    │       │       └── 打印 "c ..."（c 执行完毕，c 出栈）<br>    │       ├── 打印 "b ... after"<br>    │       └── function_b() 返回（b 出栈）<br>    ├── 打印 "a ... after"<br>    └── function_a() 返回（a 出栈）<br></code></pre> <br><p><strong>执行结果</strong>：</p> <br><pre><code class="language-python">a ... before<br>b ... add(x, y):<br>    return x + y<br>def subtract(x, y):<br>return x - y<br>def multiply(x, y):<br>return x * y<br>def divide(x, y):<br>return x / y<br>def calc(x, y, oper):        # oper 形参将来接收一个"函数"<br>return oper(x, y)        # 调用 oper 就等于调用传进来的那个函数<br>print(calc(10, 20, add))         # 30<br>print(calc(10, 20, subtract))    # -10<br>print(calc(10, 20, multiply))    # 200<br>print(calc(10, 20, divide))      # 0.5</code></pre> <br><blockquote> <br> <p><strong>函数怎么能当参数传？执行顺序是怎样的？</strong></p> <br> <ol><li>函数名不加括号时，代表的是<strong>函数对象本身</strong>（可以理解为"装着这段代码的盒子"），加括号才是"执行它"。所以 <code>calc(10, 20, add)</code> 里传的 <code>add</code> 是函数对象，而不是调用结果。</li><li>执行 <code>calc(10, 20, add)</code> 时：先给形参赋值 <code>x=10, y=20, oper=add</code>——相当于 <code>oper</code> 和 <code>add</code> 指向了同一个函数对象。</li><li>函数体内执行 <code>oper(x, y)</code>，即执行 <code>add(10, 20)</code>，得到 30 返回。</li><li>Python 是动态类型语言，形参不会限定"必须是数字还是函数"，传什么它就接收什么——<code>oper(x, y)</code> 能成立，是因为传进来的确实是"可以用两个参数调用的函数"。这也解释了<strong>为什么传函数名时不加括号</strong>：加了括号就变成"先调用 add(10, 20) 得到 30，再把 30 传给 oper"，<code>30(x, y)</code> 就报错了。</li></ol> <br></blockquote> <br><h4 id="2 7 20 E5 8C BF E5 90 8D E5 87 BD E6 95 B0">2.7 匿名函数</h4> <br><p><strong>匿名函数</strong>：没有名称的函数，通过 <code>lambda</code> 表达式声明，用于简化简单函数的编写。函数体只能是<strong>单个表达式</strong>，不能写多行语句。</p> <br><p><strong>语法格式</strong>：</p> <br><pre><code>lambda 参数列表: 函数体<br></code></pre> <br><p><strong>代码示例</strong>：</p> <br><pre><code class="language-python"># 命名函数<br>def add(x, y):<br>    return x + y<br>print(add(10, 20))               # 30<br># 匿名函数：赋给变量后按名字调用<br>add_lambda = lambda x, y: x + y<br>print(add_lambda(10, 20))        # 30<br># 匿名函数直接调用（定义后立刻执行）<br>print((lambda x, y: x + y)(10, 20))    # 30<br># 匿名函数可以不传参，函数体也可以不返回结果<br>say_hi = lambda: print("你好")<br>say_hi()                          # 你好</code></pre> <br><blockquote> <br> <p><strong>注意</strong>：</p> <br> <ul><li>匿名函数返回结果时<strong>不需要写 return</strong>，表达式的运算结果就是返回值</li><li>函数逻辑简单（单行表达式）且只在一个地方使用时才考虑 lambda，通常作为高阶函数的参数使用</li></ul> <br></blockquote> <br><p><strong>小结</strong>：</p> <br><ol><li>匿名函数定义：<code>lambda 参数列表: 函数体</code></li><li>选择建议： <br>  <ul><li>用匿名函数：逻辑简单、只在一处调用（常作高阶函数参数）</li><li>用命名函数：逻辑复杂、多步操作、多处复用、需要说明文档</li><li><strong>代码的可读性和可维护性比简洁性更重要</strong></li></ul> </li></ol> <br><h4 id="2 8 20 E5 87 BD E6 95 B0 E8 BF 9B E9 98 B6 E6 A1 88 E4 BE">2.8 函数进阶案例</h4> <br><p><strong>案例1：N 的阶乘（递归）</strong></p> <br><pre><code class="language-python">8的阶乘：8*7*6*5*4*3*2*1    f(8) = 8 * f(7)<br>7的阶乘：7*6*5*4*3*2*1      f(7) = 7 * f(6)<br>...<br>2的阶乘：2*1                f(2) = 2 * f(1)<br>1的阶乘：1                  f(1) = 1（终结点）<br>n的阶乘公式：f(n) = n * f(n-1)<br></code></pre> <br><pre><code class="language-python">def factorial(n):<br>    if n == 1:                    # 终结点（递归出口）<br>        return 1<br>    return n * factorial(n - 1)   # 自己调用自己<br>result = factorial(5)<br>print(f"5的阶乘为：{result}")     # <code>f(8)</code> → …… → 一路调用到 <code>f(1)</code>。每调用一层就在调用栈里压入一层（对应 1.5 的栈结构）。</li><li><strong>归（逐层回归）</strong>：<code>f(1)</code> 触发终结点直接返回 1 → 回到 <code>f(2)</code> 算出 <code>2*1=2</code> → 回到 <br><p><strong>案例3</strong>：根据传入的一批商品信息（商品名、价格、数量）、优惠（优惠券、积分抵扣）、运费计算订单总金额。</p> <br><p>规则：</p> <br><ul><li>优惠券需要商品金额满 5000 才可以使用，且优惠券金额不能超过商品总价</li><li>积分抵扣需要商品总金额满 5000 才可以使用，100 积分抵扣 1 商品信息元组（商品名, 价格, 数量），个数不定<br>    :param coupon: 优惠券金额（满 5000 可用，且不能超过商品总价）<br>    :param points: 积分（满 5000 可用，100 积分抵 1 元，只能整百抵扣）<br>    :param express: 运费<br>    :return: 订单总金额<br>    """<br>    # 1. <br><p><strong>类型注解</strong>：Python 中的一种语法特性，用于明确标识变量、函数参数和返回值的数据类型，使代码更清晰、更安全、更易维护。</p> <br><p><strong>变量类型注解</strong>：</p> <br><pre><code class="language-python"># 无类型注解<br>a = 695<br>score = 98.5<br>hobby = "Python"<br>flag = True<br>pic = None<br>names = ["A", "C", "E"]<br>phones = {"13309091111", "15209109121"}<br>options = {"count": 0, "total": 0}<br>goods = ("手机", 5999, 1)<br># 有类型注解：变量名: 类型 = 值<br>a: int = 695<br>score: float = 98.5<br>hobby: str = "Python"<br>flag: bool = True<br>pic: None = None<br>names: list[str] = ["A", "C", "E"]<br>phones: set[str] = {"13309091111", "15209109121"}<br>options: dict[str, int] = {"count": 0, "total": 0}<br>goods: tuple[str, int, int] = ("手机", 5999, 1)</code></pre> <br><h4 id="3 2 20 E7 B1 BB E5 9E 8B E6 8E A8 E6 96 AD">3.2 类型推断</h4> <br><p><strong>类型推断</strong>：Python 解释器自动推断变量、表达式或函数返回值的数据类型的能力，无需开发者显式声明。</p> <br><pre><code class="language-python">a = 695                              # 自动推断为 int<br>score = 98.5                         # 自动推断为 float<br>hobby = "Python"                     # 自动推断为 str<br>flag = True                          # 自动推断为 bool<br>pic = None                           # 自动推断为 NoneType<br>names = ["张三", "李四", "王五"]      # 自动推断为 list[str]<br></code></pre> <br><blockquote> <br> <p><strong>注意</strong>：直接赋值、变量运算、容器推导等场景下，解释器会自动推导类型。</p> <br></blockquote> <br><p><strong>小结</strong>：</p> <br><ol><li>类型注解的写法：<code>变量: 数据类型</code>（如 <code>a: int</code>）</li><li>常见类型写法：<code>int</code>、<code>float</code>、<code>bool</code>、<code>str</code>、<code>None</code>、<code>list[str]</code>、<code>set[str]</code>、<code>tuple[str, int]</code>、<code>dict[str, int]</code>、<code>str | int</code>（联合类型）</li><li>为什么要使用类型注解？ <br>  <ul><li>代码结构更清晰</li><li>代码逻辑更安全、易维护</li><li>更准确的代码自动提示</li><li>提前发现代码潜在问题</li></ul> </li><li><strong>Python 是动态类型语言，类型注解只是提示，并不是强制约束！</strong></li></ol> <br><h4 id="3 3 20 E5 87 BD E6 95 B0 E7 B1 BB E5 9E 8B E6 B3 A8 E8 A7">3.3 函数类型注解</h4> <br><p>为函数添加类型注解，主要是为<strong>参数</strong>和<strong>返回值</strong>添加注解。</p> <br><p><strong>语法格式</strong>：</p> <br><pre><code class="language-python">def 函数名(参数名: 参数类型) -> 返回值类型:<br>    函数体<br>    return 返回值<br></code></pre> <br><p><strong>代码示例</strong>：</p> <br><pre><code class="language-python">def calc(scores: list[int]) -> float:<br>    return sum(scores) / len(scores)<br>def calc_data(scores:
