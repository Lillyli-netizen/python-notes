### 一、函数基础

#### 1.1 什么是函数

**函数**是组织好的、可重复使用的、用来实现特定功能的代码片段。

**为什么需要函数？**

- `input()`、`print()`、`max()`、`min()`、`len()`、`sum()` 等都是 Python 的内置函数
- 它们是提前定义好的、可以重复使用的、实现特定功能的代码
- 函数的核心价值：**代码复用、逻辑封装、便于维护**

#### 1.2 函数的定义与调用

**语法格式**：

```
# 定义函数
def 函数名(参数列表):
    函数体
    ......
    return 返回值
# 调用函数
函数名(参数)
```

**代码示例**：

```
# 定义函数：打印一条分隔线
def out_line():
    print('-------------------------------')
# 调用函数
out_line()
# 自己练习：定义与调用
def myfunc():
print("Hello World")   # 函数体必须缩进
myfunc()
```

**注意事项**：

1. 函数定义时的参数列表与 `return` 语句可有可无（由需求确定）
2. 函数必须**先定义后调用**，按代码顺序执行，调用一次执行一次
3. 函数定义时内部代码并不执行，只有在调用时才执行
4. 函数体通过缩进来描述归属关系

**小结**：

1. 函数定义及调用的语法：

   ```
   def 函数名():
       函数体
   函数名()
   ```
2. 注意事项：先定义后调用；定义时不执行、调用时才执行；缩进表示归属。

#### 1.3 函数的参数与返回值

**定义函数时**，根据业务需要，可以指定参数与返回值。

```
# 定义函数
def 函数名(参数列表):
    函数体
    ......
    return 返回值      # return 通常写在函数体的最后一行
# 调用函数
函数名(参数)
```

> **怎么决定"要不要参数、要不要 return"？**（一个简单的判断方法）
>
> - **参数 = 函数需要的"原料"**：函数体里要用到的、但函数自己不知道的数据（比如半径 r），就从参数传进来。缺什么传什么。
> - **return = 函数的"产出"**：函数算完的结果，调用者还要拿来用的（存变量、参与后续运算、打印），就 return 回去；如果函数的目的只是"打印显示"（如 `out_line()`），就不需要 return。
> - **外面有的、函数要用的 → 参数；函数算出的、外面要用的 → return**。

**示例1：计算圆的面积**

```
def circle_area(r):
    area = 3.14 * r * r
    return area
# 调用函数：用变量接收返回值
c_area = circle_area(10)
print(c_area)           # 314.0
# 也可以直接把调用放进 print 里
print(circle_area(2))   # 12.56
```

> **只写 `circle_area(2)` 不接收可以吗？** 可以调用、函数会执行，但返回值被直接丢弃了，等于白算。要么用变量接收后再用，要么直接 `print(circle_area(2))`。

**示例2：计算长方形的面积**

```
def rectangle_area(l, w):
    area = l * w
    return area
r_area = rectangle_area(20, 10)
print(r_area)           # 200
```

**核心概念**：

| 概念 | 说明 |
| --- | --- |
| **形参（形式参数）** | 函数定义时括号里的参数名，只能在函数内使用（局部变量） |
| **实参（实际参数）** | 函数调用时实际传入的具体值 |

> **形参和实参是什么关系？**
>
> 形参是定义时起的"**占位变量名**"，实参是调用时给出的"**具体值**"。调用时，实参的值会按位置（或按关键字）一一赋给形参——相当于执行了一次 `形参 = 实参` 的赋值。例如 `rectangle_area(20, 10)`：`l = 20`、`w = 10`，函数体内用的是 l 和 w，而它们拿到的正是调用时传的 20 和 10。

> **注意**：函数定义时有多个参数，参数之间用逗号 `,` 分隔。

> **注意**：`return` 只负责把值交回给调用处，**没有打印功能**。要显示结果，需用变量接收后 `print()`，或直接把函数调用写进 `print()` 里。

**函数可以返回多个值**（多个值之间用逗号分隔，自动封装为元组）：

```
def circle_area_len(r):
    return round(3.14 * r * r, 1), round(2 * 3.14 * r, 1)
# 方式一：接收为一个元组
al = circle_area_len(10)
print(al)               # (314.0, 62.8)
print(type(al))         # <class 'tuple'>
# 方式二：解包接收（变量个数与返回值个数一致）
area, length = circle_area_len(3)
print(area, length)     # 28.3 18.8
```

> 小提醒：接收解包的变量不要命名为 `len`，它会覆盖内置函数 `len()`。

**小结**：

1. 有参数有返回值的函数：

   ```
   def rectangle_area(l, w):
       return l * w
   r_area = rectangle_area(20, 10)
   print(r_area)
   ```
2. 函数可以返回多个值，返回结果为元组类型，可以通过解包方式接收。

#### 1.4 函数的说明文档

**函数的说明文档（Docstring）**：写在函数开头、用三引号包裹的字符串，用于解释函数的功能、参数、返回值等信息，方便调用者了解函数的作用与细节。

**语法格式**：

```
def 函数名(参数列表):
    """
    函数功能描述
    :param 参数名: 参数说明
    :return: 返回值说明
    """
    函数体
    return 返回值
```

**代码示例**：

```
def circle_area_len(r):
    """
    该函数用于根据圆的半径，计算圆的面积和圆的周长
    :param r: 圆的半径
    :return: 圆的面积，圆的周长
    """
    return round(3.14 * r * r, 1), round(2 * 3.14 * r, 1)
al = circle_area_len(10)
print(al)    # (314.0, 62.8)
def rectangle_area(l, w):
"""
根据长方形的长度和宽度计算面积
:param l: 长度
:param w: 宽度
:return: 长方形的面积
"""
area = l * w
return area
help() # 查看说明文档：只传函数名，不要加函数后面括号
help(rectangle_area)
```

> **`help()` 里查看函数为什么函数不能加括号？**
>
> `比如rectangle_area` 是函数对象本身，`help()` 需要的就是它；写成 `rectangle_area()` 会先"调用"函数——而它需要两个参数，调用会直接报错。**传函数给别人时用名字（不带括号），调用执行时才加括号。**

**查看说明文档的两种方式**：

- 使用 `help()` 函数：`help(circle_area_len)`
- 鼠标悬浮在函数名上，IDE 自动展示（推荐）

> **记住**：好的文档，能让你的代码更容易理解、使用和维护！

#### 1.5 函数的嵌套调用

**嵌套调用**：在一个函数中，又调用了另外一个函数。

**函数调用遵循栈结构**：每调用一个函数，就把一层"调用记录"压入调用栈；函数执行完毕，就弹出这一层（出栈），回到调用它的地方继续执行。最后被调用的函数最先返回（**LIFO：Last In First Out，后进先出**）。

> **结合示例理解出栈顺序**
>
> `function_a()` 先压栈
>
> → 执行到 `function_b()` 时 b 压栈
>
> → b 执行到 `function_c()` 时 c 压栈
>
> → c 打印完 `"c ..."` 就执行完了，**c 最先出栈**
>
> → 回到 b，继续执行 b 里剩下的 `print("b ... after")`，b 执行完毕出栈
>
> → 回到 a，执行 `print("a ... after")`，a 最后出栈。
>
> 就像子弹弹夹：**最后压进去的子弹最先打出来**（后进先出）。

**代码示例**：

```
def function_a():
    print("a ... before")
    function_b()
    print("a ... after")
def function_b():
print("b ... before")
function_c()
print("b ... after")
def function_c():
print("c ...")
function_a()
```

**执行流程**：

```
function_a() 开始（a 压栈）
    ├── 打印 "a ... before"
    ├── 调用 function_b()（b 压栈）
    │       ├── 打印 "b ... before"
    │       ├── 调用 function_c()（c 压栈）
    │       │       └── 打印 "c ..."（c 执行完毕，c 出栈）
    │       ├── 打印 "b ... after"
    │       └── function_b() 返回（b 出栈）
    ├── 打印 "a ... after"
    └── function_a() 返回（a 出栈）
```

**执行结果**：

```
a ... before
b ... before
c ...
b ... after
a ... after
```

**小结**：

- 嵌套调用：在一个函数中调用另外一个函数
- 调用遵循栈结构：后进先出（LIFO），最后被调用的函数最先返回

#### 1.6 函数基础案例

**案例1**：根据传入的底和高计算三角形面积（面积 = 底 × 高 / 2）。

```
def triangle_area(base, height):
    return base * height / 2
area = triangle_area(10, 5)
print(f"三角形面积为：{area}")      # 25.0
```

**案例2**：计算传入的字符串中元音字母的个数（元音字母为 aeiouAEIOU）。

```
def count_vowels(s):
    count = 0                    # 计数器必须在循环之前初始化（函数内、循环外）
    for ch in s:                 # 逐个字符遍历
        if ch in "aeiouAEIOU":   # 当前字符是元音字母
            count += 1
    return count
result = count_vowels("Hello Python")
print(f"元音字母个数：{result}")     # 3（e、o、o）
```

> **案例二错误集锦**
>
> ```
> def count_vowels(str):                # 问题1：str 是内置类型名，做参数名会覆盖它，应改名为 s
>     if str in "aeiouAEIOU":      # 问题2：判断的是"整个字符串"是否在元音串里，
>         count = 0                #         而不是逐个字符统计——缺少 for 遍历
>         count += 1               # 问题3：count 在 if 内部初始化，条件不满足时
>     return count                 #         return count 会报 NameError（count 未定义）
> ```
>
> 正确思路：
>
> **计数器在循环外初始化 → for 遍历每个字符 → 是元音就加 1 → 循环结束返回**。
>
> count 不是要定义在"全局"，而是要**定义在函数内、循环之前**，保证整个函数体里都能访问且只初始化一次。

**案例3**：计算传入的成绩列表的最高分、最低分、平均分（保留 1 位小数），并返回。

```
def calc_score(score_list):
    max_s = max(score_list)
    min_s = min(score_list)
    avg_s = round(sum(score_list) / len(score_list), 1)
    return max_s, min_s, avg_s
s_list = [589, 609, 605, 643, 677, 455, 477, 489, 503]
max_score, min_score, avg_score = calc_score(s_list)
print(f"最高分：{max_score}，最低分：{min_score}，平均分：{avg_score}")
```

> **易错点**：函数开头不要再写声明比如 `score_list = []`——这会把传入的实参**重新赋值为空列表**，后面 max/min/sum 全部报错。**形参的值来自实参，函数内不要再覆盖它**。

**案例4**：根据传入的分数，计算对应的分数等级并返回（>=90：A；>=75：B；>=60：C；<60：D）。

```
def get_grade(score):
    if score >= 90:
        return "A"
    elif score >= 75:
        return "B"
    elif score >= 60:
        return "C"
    else:
        return "D"
score = float(input("请输入分数："))   # input 返回字符串，必须转成数字才能比较大小
print(f"等级：{get_grade(score)}")
```

> **容易出现的两个问题**：
>
> - `input()` 返回字符串，字符串无法与数字比较大小（会直接报 TypeError），要先 `float()` / `int()` 转换；
> - 函数体里用 `print` 而不是 `return` 时，函数没有返回值（默认返回 `None`），此时 `s = cal(...)` 得到的 `s` 是 `None`，IDE 也会给出黄色警告。
> - **要"返回结果给调用者"就用 return；要"显示"就在函数外 print。**

**案例5**：判断一个字符串是否是回文串，返回 bool 值。

```
def is_palindrome(s):
    return s == s[::-1]          # 比较表达式的结果本身就是布尔值，直接返回即可
print(is_palindrome("level"))    # True
print(is_palindrome("hello"))    # False
# 自己练习的等价写法：
# if/else 分别返回 True/False，效果相同但更啰嗦
def is_palindrome(s):
if s == s[::-1]:
return True
else:
return False
```

**案例6**：将传入的秒转换为小时、分钟、秒。

```
def convert_time(seconds):
    hours = seconds // 3600              # 整除：有多少个完整的小时
    minutes = (seconds % 3600) // 60     # 先取除以3600的余数（剩下的秒），再整除60得到分钟
    secs = seconds % 60                  # 取余：最后不足1分钟的零头秒数
    return hours, minutes, secs
h, m, s = convert_time(3661)
print(f"{h}小时{m}分钟{s}秒")    # 1小时1分钟1秒
```

> **为什么用 `//` 和 `%`？**
>
> `//` 是整除（只要商、丢掉余数），`%` 是取余（只要余数）。
>  以 3661 秒为例：`3661 // 3600 = 1` → 1 小时；`3661 % 3600 = 61` → 剩下 61 秒；`61 // 60 = 1` → 1 分钟；`61 % 60 = 1` → 1 秒。
>
> **整除求"有几个完整单位"，取余求"剩下多少"**，两者搭配是时间/单位换算的固定套路。

**案例7**：根据三角形三边边长，判定三角形类型。

```
def triangle_type(a, b, c):
    if a + b > c and a + c > b and b + c > a:
        if a == b == c:
            return "等边三角形"
        elif a == b or a == c or b == c:
            return "等腰三角形"
        else:
            return "普通三角形"
    else:
        return "不能构成三角形"
print(triangle_type(3, 3, 3))    # 等边三角形
print(triangle_type(3, 3, 4))    # 等腰三角形
print(triangle_type(3, 4, 5))    # 普通三角形
print(triangle_type(1, 2, 5))    # 不能构成三角形
```

### 二、函数进阶

#### 2.1 变量作用域

**变量的作用域**：变量的作用范围（在哪里可以使用，在哪里不可以使用）。

| 类型 | 说明 |
| --- | --- |
| **全局变量** | 在函数之外定义的变量，整个文件中（包括函数内）都可以使用（通常定义在文件顶部） |
| **局部变量** | 在函数内部定义的变量，只能在函数内部使用 |

**代码示例**：

```
num = 100                    # 全局变量
def circle_area(r):
    pi = 3.14                # 局部变量：只能在函数内使用
    area = pi * r * r        # r、pi、area 都是局部变量
    return area

c_area = circle_area(10)
print(c_area)                # 314.0
print(pi)                  # 报错 NameError：函数外无法访问局部变量
print(num)                   # 100：全局变量哪里都能用
```

#### 2.2 global 关键字

`global` 关键字用于告诉解释器：函数内接下来使用的这个变量是全局变量，从而可以在函数内部**修改**全局变量的值。

**不使用 global**（函数内只是新建了一个同名局部变量）：

```
num1 = 1               # 全局变量
def fun1():
    num1 = 100         # 这是新建的局部变量，与全局变量无关
    print(num1)
fun1()                 # 100
print(num1)            # 1（全局变量未改变）
```

**使用 global**：

```
num1 = 1               # 全局变量
def fun1():
    global num1        # 声明：接下来用的是全局变量 num1
    num1 = 100         # 修改的是全局变量本身
    print(num1)
fun1()                 # 100
print(num1)            # 100（全局变量已改变）
```

> **注意**：使用 `global` 时要**先声明、再使用**（声明语句通常写在函数体开头）。

**global 的典型应用场景：用全局变量保存程序状态（调试开关）**

```
# 调试开关：一个全局变量记录程序当前的状态
debug_mode = False
def enable_debug_mode():
    global debug_mode
    debug_mode = True
    print("调试模式已开启")
def disable_debug_mode():
    global debug_mode
    debug_mode = False
    print("调试模式已关闭")
enable_debug_mode()     # 调试模式已开启
print(debug_mode)       # True
disable_debug_mode()    # 调试模式已关闭
print(debug_mode)       # False
```

**小结**：

1. 局部变量：函数内部定义，函数外不可用；全局变量：函数外部定义，哪里都能用
2. `global`：在函数内部声明"接下来使用的是全局变量"，从而可以修改它
3. 注意事项：
   - 尽量避免在函数中修改全局变量，会使代码难以维护
   - 优先考虑用函数参数和返回值传递数据
   - `global` 主要用在程序状态、配置、计数器等场景

#### 2.3 函数传参方式

**传参方式**：调用函数时传递实参的方式。

##### 2.3.1 位置参数

调用函数时，按形参定义的**位置顺序**一一对应传值。

```
def reg_stu(name, age, gender, city):
    print(f"注册成功，姓名:{name}, 年龄:{age}, 性别:{gender}, 城市:{city}")
    return {"name": name, "age": age, "gender": gender, "city": city}
# 调用函数（位置参数）：顺序必须与定义时完全一致
stu = reg_stu("张三", 18, "男", "北京")
print(stu)
```

> **要求**：实参顺序与形参顺序完全一致，否则数据就"串位"了。

##### 2.3.2 关键字参数

调用函数时，以"形参名=值"的形式传参，**不要求顺序**。

```
# 关键字参数：顺序随便
stu = reg_stu(name="张三", age=18, gender="男", city="北京")
print(stu)
stu2 = reg_stu(gender="男", name="王武", city="上海", age=22)
print(stu2)
# 混合使用：位置参数在前，关键字参数在后
stu3 = reg_stu("赵四", 28, gender="男", city="上海")
print(stu3)
```

> **要求**：位置参数与关键字参数混用时，**关键字参数必须写在位置参数之后**；关键字参数之间没有顺序要求。

**两种传参方式对比**：

| 对比项 | 位置参数 | 关键字参数 |
| --- | --- | --- |
| **优点** | 简洁 | 可读性强、易维护和扩展 |
| **缺点** | 可读性差、易出错、维护难 | 代码繁琐 |
| **适用场景** | 参数少（不超过 3 个）且顺序自然 | 参数较多，或容易混淆的场景 |

> **黄金法则**：半年后回头看你今天写的代码，能否一眼看出每个参数的含义？如果不能，就应该使用关键字参数。

**小结**：

1. 位置参数：实参顺序与形参顺序完全一致
2. 关键字参数："形参名=值"形式传递，顺序没有要求
3. 选择原则：以可读性、可维护性为目标——参数少用位置参数，参数多或易混淆用关键字参数

#### 2.4 默认参数

**默认参数**（缺省参数）：定义函数时为参数提供默认值，调用时可以不传该参数。

```
def reg_stu(name, age, gender, city='北京'):   # city 是默认参数，必须放在参数列表最后
    print(f"注册成功, 姓名:{name}, 年龄:{age}, 性别:{gender}, 城市:{city}")
    return {"name": name, "age": age, "gender": gender, "city": city}
# 调用时没传 city：使用默认值
stu = reg_stu("张三", 18, "男")
print(stu)              # 城市: 北京
# 调用时传了 city：覆盖默认值
stu = reg_stu("赵四", 22, "男", "深圳")
print(stu)              # 城市: 深圳
```

> **注意**：
>
> - 默认参数必须放在**没有默认值的参数后面**，否则报错（如 `def f(city='北京', name)` 是非法的——Python 无法判断 `f("张三")` 里的 "张三" 该给谁）
> - 一个函数可以设置多个默认参数
> - 调用时传了值就用传入的值，没传就用默认值

#### 2.5 不定长参数

**介绍**：不定长参数（可变参数）用于参数个数不确定（0 个或多个）的场景。

**类型**：位置传递（`*args`）、关键字传递（`**kwargs`）。

##### 2.5.1 位置传递（\*args）

```
def calc_data(*args):
    print(args)          # args 是一个元组
    print(type(args))    # <class 'tuple'>
calc_data(10, 20, 30, 40, 50)    # (10, 20, 30, 40, 50)
calc_data()                      # ()（0 个参数也合法）
```

**应用：根据传入的一批数据，计算最小值、最大值、平均值**

```
def calc_data(*args):
    min_data = min(args)
    max_data = max(args)
    avg_data = sum(args) / len(args)
    return min_data, max_data, avg_data
print(calc_data(2, 7, 9, 10, 45))    # (2, 45, 14.6)
```

> **注意**：
>
> - 调用时传入的所有位置实参都会被 `args` 收集，封装为一个**元组**（不会收集关键字参数）
> - `args` 只是约定俗成的变量名，不是关键字，写成 `*data` 等任何合法变量名都可以，起作用的是 `*`

##### 2.5.2 关键字传递（\*\*kwargs）

```
def calc_data(*args, **kwargs):
    min_data = min(args)
    max_data = max(args)
    avg_data = sum(args) / len(args)

    # kwargs 是字典，用 get() 取选项：没传就返回 None，不报错
    if kwargs.get("round") is not None:      # 传了 round=N：平均值保留 N 位小数
        avg_data = round(avg_data, kwargs.get("round"))

    if kwargs.get("print"):                  # 传了 print=True：函数内打印计算结果
        print(f"最小值:{min_data}, 最大值:{max_data}, 平均值:{avg_data}")

    return min_data, max_data, avg_data

# 调用1：数字被 *args 收集成元组，round/print 被 **kwargs 收集成字典
print(calc_data(2, 7, 9, 10, 45, round=3, print=True))
# 先打印一行：最小值:2, 最大值:45, 平均值:14.6，再返回 (2, 45, 14.6)

# 调用2：一个选项都不传也完全合法
print(calc_data(2, 7, 9, 10, 45, 73, 37, 93, 92, 111, 222))    # (2, 222, 59.3636...)
```

> **kwargs 到底是什么？**
>
> - 调用时写的所有 `"键=值"` 形式的实参，会被 `**kwargs` 统一收集，封装为一个**字典**：`{"round": 3, "print": True}`。函数内部用 `kwargs.get("键名")` 读取。
> - **键名完全自定义**，不限于 `round`、`print`，你写 `level=5`、`mode="fast"` 都行；`round`、`print` 在这里只是选的两个选项名。
> - **不是必须出现**：一个选项都不传时，kwargs 是空字典 `{}`，`kwargs.get(...)` 返回 `None`，函数照常工作。
> - **为什么不把这些选项写死成普通形参？** 因为选项的个数和内容不确定——今天要"是否打印"，明天可能要"精度""分隔符"。`**kwargs` 让函数不必预先定义所有选项就能接受任意配置，这就是它"定制函数行为"的价值：调用者**按需传、传了才生效**。

**小结**：

1. 不定长参数：参数个数不确定时使用
2. 分类：
   - `*args`：不定长**位置**参数，封装为**元组**
   - `**kwargs`：不定长**关键字**参数，封装为**字典**
3. 应用场景：
   - `*args`：处理数量不确定的数据
   - `**kwargs`：处理数量不确定的选项（配置参数，定制函数行为）

#### 2.6 函数作为参数传递

- **普通参数**：数字、布尔、字符串、列表、元组、集合、字典等
- **特殊参数**：函数（函数也可以作为参数传给另一个函数，即**高阶函数**）

```
def add(x, y):
    return x + y
def subtract(x, y):
return x - y
def multiply(x, y):
return x * y
def divide(x, y):
return x / y
def calc(x, y, oper):        # oper 形参将来接收一个"函数"
return oper(x, y)        # 调用 oper 就等于调用传进来的那个函数
print(calc(10, 20, add))         # 30
print(calc(10, 20, subtract))    # -10
print(calc(10, 20, multiply))    # 200
print(calc(10, 20, divide))      # 0.5
```

> **函数怎么能当参数传？执行顺序是怎样的？**
>
> 1. 函数名不加括号时，代表的是**函数对象本身**（可以理解为"装着这段代码的盒子"），加括号才是"执行它"。所以 `calc(10, 20, add)` 里传的 `add` 是函数对象，而不是调用结果。
> 2. 执行 `calc(10, 20, add)` 时：先给形参赋值 `x=10, y=20, oper=add`——相当于 `oper` 和 `add` 指向了同一个函数对象。
> 3. 函数体内执行 `oper(x, y)`，即执行 `add(10, 20)`，得到 30 返回。
> 4. Python 是动态类型语言，形参不会限定"必须是数字还是函数"，传什么它就接收什么——`oper(x, y)` 能成立，是因为传进来的确实是"可以用两个参数调用的函数"。这也解释了**为什么传函数名时不加括号**：加了括号就变成"先调用 add(10, 20) 得到 30，再把 30 传给 oper"，`30(x, y)` 就报错了。

#### 2.7 匿名函数

**匿名函数**：没有名称的函数，通过 `lambda` 表达式声明，用于简化简单函数的编写。函数体只能是**单个表达式**，不能写多行语句。

**语法格式**：

```
lambda 参数列表: 函数体
```

**代码示例**：

```
# 命名函数
def add(x, y):
    return x + y
print(add(10, 20))               # 30
# 匿名函数：赋给变量后按名字调用
add_lambda = lambda x, y: x + y
print(add_lambda(10, 20))        # 30
# 匿名函数直接调用（定义后立刻执行）
print((lambda x, y: x + y)(10, 20))    # 30
# 匿名函数可以不传参，函数体也可以不返回结果
say_hi = lambda: print("你好")
say_hi()                          # 你好
```

> **注意**：
>
> - 匿名函数返回结果时**不需要写 return**，表达式的运算结果就是返回值
> - 函数逻辑简单（单行表达式）且只在一个地方使用时才考虑 lambda，通常作为高阶函数的参数使用

**小结**：

1. 匿名函数定义：`lambda 参数列表: 函数体`
2. 选择建议：
   - 用匿名函数：逻辑简单、只在一处调用（常作高阶函数参数）
   - 用命名函数：逻辑复杂、多步操作、多处复用、需要说明文档
   - **代码的可读性和可维护性比简洁性更重要**

#### 2.8 函数进阶案例

**案例1：N 的阶乘（递归）**

```
8的阶乘：8*7*6*5*4*3*2*1    f(8) = 8 * f(7)
7的阶乘：7*6*5*4*3*2*1      f(7) = 7 * f(6)
...
2的阶乘：2*1                f(2) = 2 * f(1)
1的阶乘：1                  f(1) = 1（终结点）
n的阶乘公式：f(n) = n * f(n-1)
```

```
def factorial(n):
    if n == 1:                    # 终结点（递归出口）
        return 1
    return n * factorial(n - 1)   # 自己调用自己
result = factorial(5)
print(f"5的阶乘为：{result}")     # 120
```

> **递归执行过程（以 n=10 为例）**
>
> - **递（层层递进）**：`f(10)` 要等 `f(9)` 的结果 → `f(9)` 等待 `f(8)` → …… → 一路调用到 `f(1)`。每调用一层就在调用栈里压入一层（对应 1.5 的栈结构）。
> - **归（逐层回归）**：`f(1)` 触发终结点直接返回 1 → 回到 `f(2)` 算出 `2*1=2` → 回到 `f(3)` 算出 `3*2=6` → …… → `f(10)` 算出 3628800。
> - **必须要有终结点**，否则会无限调用自己，直到超出 Python 的最大递归深度（默认约 1000 层）报 `RecursionError`。

**案例2**：根据班级名称和各学员总分，统计平均分及高于/低于平均分的人数。

```
def class_stats(class_name, *scores):
    avg = sum(scores) / len(scores)
    above = sum(1 for s in scores if s > avg)    # 生成器：统计满足条件的个数
    below = sum(1 for s in scores if s < avg)
    print(f"班级：{class_name}")
    print(f"平均分：{avg:.1f}")
    print(f"高于平均分人数：{above}")
    print(f"低于平均分人数：{below}")
class_stats("Python01班", 589, 609, 605, 643, 677, 455, 477, 489, 503)
```

**案例3**：根据传入的一批商品信息（商品名、价格、数量）、优惠（优惠券、积分抵扣）、运费计算订单总金额。

规则：

- 优惠券需要商品金额满 5000 才可以使用，且优惠券金额不能超过商品总价
- 积分抵扣需要商品总金额满 5000 才可以使用，100 积分抵扣 1 元（抵扣金额不能超过商品总价，积分只能整百抵扣）

```
def calc_cart_total(*goods, coupon=0, points=0, express=0):
    """
    根据商品信息、优惠券、积分抵扣、运费计算订单总金额
    :param goods: 商品信息元组（商品名, 价格, 数量），个数不定
    :param coupon: 优惠券金额（满 5000 可用，且不能超过商品总价）
    :param points: 积分（满 5000 可用，100 积分抵 1 元，只能整百抵扣）
    :param express: 运费
    :return: 订单总金额
    """
    # 1. 商品总金额：推导式把每个商品的 价格*数量 累加（等价于 for 循环逐个累加）
    total = sum(price * num for _, price, num in goods)
    # 2. 优惠券：满 5000 且不超过商品总价才抵扣
    if total >= 5000 and coupon <= total:
        total -= coupon
    # 3. 积分抵扣：100 积分抵 1 元（整百抵扣），抵扣额不超过商品总价
    if total >= 5000 and points // 100 <= total:
        total -= points // 100
    # 4. 加上运费
    return total + express
total = calc_cart_total(("鼠标", 100, 3), ("键盘", 500, 200), coupon=50, points=3000, express=5)
print(total)    # 100225（商品总价 100300 → 减优惠券 50 → 减积分抵扣 30 → 加运费 5）
```

> **容易出现的问题汇总**：
>
> - **循环变量与下标混淆**：`for i in args:` 里 i 是每个商品元组，应取 `i[1] * i[2]`（价格×数量），而不是 `args[1] * args[2]`（那是对"元组的元组"取下标）
> - **覆盖形参**：`score = score // 100` 直接改了参数值，虽然此处可行，但更清晰的做法是用新变量存抵扣额
> - **条件写错**：积分抵扣的"不能超过商品总价"应与商品总价 `total` 比较，而不是写死 `<= 5000`
> - **函数里 是否print 提示信息**：计算型函数应专注计算并返回结果，"金额不足"这类提示交给调用者处理更合适
>
> **关于传参方式**：`coupon`、`points`、`express` 写在 `*goods` 之后，语法上就**只能用关键字参数传递**（这也是 `*` 后面参数的强制规则）；给它们设置默认值 `=0` 后，调用时哪项优惠都不传也能正常运行。
>
> **`sum(price * num for _, price, num in goods)` 中的 `_`**：循环解包时用 `_` 命名"用不到的元素"（商品名），这是约定俗成的写法。

### 三、类型注解

#### 3.1 类型注解介绍

**类型注解**：Python 中的一种语法特性，用于明确标识变量、函数参数和返回值的数据类型，使代码更清晰、更安全、更易维护。

**变量类型注解**：

```
# 无类型注解
a = 695
score = 98.5
hobby = "Python"
flag = True
pic = None
names = ["A", "C", "E"]
phones = {"13309091111", "15209109121"}
options = {"count": 0, "total": 0}
goods = ("手机", 5999, 1)
# 有类型注解：变量名: 类型 = 值
a: int = 695
score: float = 98.5
hobby: str = "Python"
flag: bool = True
pic: None = None
names: list[str] = ["A", "C", "E"]
phones: set[str] = {"13309091111", "15209109121"}
options: dict[str, int] = {"count": 0, "total": 0}
goods: tuple[str, int, int] = ("手机", 5999, 1)
```

#### 3.2 类型推断

**类型推断**：Python 解释器自动推断变量、表达式或函数返回值的数据类型的能力，无需开发者显式声明。

```
a = 695                              # 自动推断为 int
score = 98.5                         # 自动推断为 float
hobby = "Python"                     # 自动推断为 str
flag = True                          # 自动推断为 bool
pic = None                           # 自动推断为 NoneType
names = ["张三", "李四", "王五"]      # 自动推断为 list[str]
```

> **注意**：直接赋值、变量运算、容器推导等场景下，解释器会自动推导类型。

**小结**：

1. 类型注解的写法：`变量: 数据类型`（如 `a: int`）
2. 常见类型写法：`int`、`float`、`bool`、`str`、`None`、`list[str]`、`set[str]`、`tuple[str, int]`、`dict[str, int]`、`str | int`（联合类型）
3. 为什么要使用类型注解？
   - 代码结构更清晰
   - 代码逻辑更安全、易维护
   - 更准确的代码自动提示
   - 提前发现代码潜在问题
4. **Python 是动态类型语言，类型注解只是提示，并不是强制约束！**

#### 3.3 函数类型注解

为函数添加类型注解，主要是为**参数**和**返回值**添加注解。

**语法格式**：

```
def 函数名(参数名: 参数类型) -> 返回值类型:
    函数体
    return 返回值
```

**代码示例**：

```
def calc(scores: list[int]) -> float:
    return sum(scores) / len(scores)
def calc_data(scores: list[int]) -> tuple[int, int, float]:
max_v = max(scores)
min_v = min(scores)
avg_v = sum(scores) / len(scores)
return max_v, min_v, avg_v
```

**案例**：为购物车总金额计算函数添加合理的类型注解。

```
def calc_cart_total_price(
    *goods: tuple[str, float, int],      # 每个商品是 (名称, 价格, 数量) 元组
    coupon_price: float = 0,             # 价格类参数标 float：float 兼容 int（传 100 也符合 float 注解）
    point_deduction: float = 0,
    express_price: float = 0
) -> float:
    """
    根据商品信息、优惠信息、运费信息计算购物车总金额
    :param goods: 商品信息（商品名、价格、数量）
    :param coupon_price: 优惠券金额
    :param point_deduction: 积分抵扣金额
    :param express_price: 运费金额
    :return: 购物车总金额
    """
    total_price = sum(good[1] * good[2] for good in goods)
    if total_price > 5000 and coupon_price <= total_price:
        total_price -= coupon_price
    if total_price > 5000 and point_deduction // 100 <= total_price:
        total_price -= point_deduction
    return total_price + express_price
```

> **关于默认参数要不要写注解**：参数给了默认值 `0` 时，解释器能自动推断类型，注解可以省略；但显式标注 `float` 更明确——它同时表达了"这个参数应该是数字（价格），可能有小数"的设计意图，对调用者是更好的提示。

**小结**：

- 函数类型注解的语法：

  ```
  def calc_data(scores: list[int]) -> tuple[int, int, float]:
  ```
- 对于需要团队协作开发和长期维护的项目，推荐使用类型注解。
