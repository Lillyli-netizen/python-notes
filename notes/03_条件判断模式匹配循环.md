## 一、条件判断

#### 1.1 if 语句基本格式

**场景**：只有满足指定条件，才会执行对应的代码逻辑。

**语法格式**：

```
if 要判断的条件:
    条件成立时，要执行的操作1
    条件成立时，要执行的操作2
```

**代码示例**：

```
# input() 返回字符串，参与数值比较前先转成 int
score = int(input("请输入成绩："))
# 如果分数超过 680，输出欢迎信息
if score >= 680:
    print("欢迎你，来清华读书")
    print("也恭喜你即将踏入精彩的大学生活")
```

> **如果把 if 代码块里的某一行再多缩进一层会怎样？**
>
> ```
> if score > 680:
>     print("欢迎你，来清华读书")
>         print("也恭喜你即将踏入精彩的大学生活")   # 报错：IndentationError: unexpected indent
> ```
>
> Python 通过缩进判断代码归属。多缩进一层意味着"开启了新的子代码块"，而**开启新代码块必须由 `if`、`for`、`while`、`def` 等复合语句引导**；普通语句后面跟着更深缩进的代码，解释器无法确定它属于谁，就会报 `IndentationError: unexpected indent`。所以同一代码块内的语句必须保持相同的缩进。

**注意事项**：

1. 判断条件的结果一定要是布尔类型（`True` / `False`）
2. 不要忘记判断条件后的冒号 `:`
3. if 代码块需要缩进（建议 4 个空格），Python 通过缩进来描述代码的层级关系（归属）；在 PyCharm 中按 Tab 键会自动转为空格

#### 1.2 案例：B站登录

**需求**：结合前面学习的输入输出及 if 条件判断的知识，完成 B 站登录功能（正确账号和密码为 `18888888888` / `666888`）。

1. 提示用户输入账号和密码。
2. 判断账号和密码是否正确：如果都正确，则登录成功，进入 B 站首页。
3. 如果账号和密码有一个错误，则登录失败，提示错误信息。

**参考代码**：

```
# 正确的账号和密码（按字符串处理更合理：input 返回字符串，且账号可能含前导 0）
ok_account = "18888888888"
ok_password = "666888"
account = input("请输入B站账号：")
password = input("请输入B站密码：")
if account == ok_account and password == ok_password:
print("登录成功~")
print("进入B站首页~")
else:
print("登录失败！")
print("用户名或密码错误！")
```

> **为什么用 if...else 而不是两个独立的 if？** 初学容易写成"先判断成功、再单独判断失败"两个 if。功能上可行，但每次登录两个条件都要判断一遍；登录的成功与失败本来就互斥，用 if...else 的两个分支表达更简洁高效。另外，`else: print("登录失败")` 写在同一行虽然语法允许，但不符合 PEP 8 风格，建议 else 单独一行、代码块换行缩进。

#### 1.3 if...else 结构

**语法格式**：

```
if 要判断的条件:
    条件成立时，执行的操作1
else:
    条件不成立时，执行的操作2
```

**执行流程**：

```
开始 → 条件判断 → True  → 操作1
              → False → 操作2
```

**代码示例**：

```
score = 695
if score > 680:
    print("欢迎你，来清华读书")
else:
    print("继续努力，再接再厉")
```

**注意事项**：

1. `else` 不需要写条件，当 if 条件不成立时，自动执行 else 代码块
2. else 及其代码块同样需要缩进（建议 4 个空格）

#### 1.4 if...else 练习

age = int(input("请输入您的年龄："))
if age >= 18:

else:
    print("未成年")
```

num = float(input("请输入一个数字："))

#### 1.5 案例：判断闰年

**需求**：根据用户输入的年份，判断这一年是闰年还是平年。

- 非整百年份，能被 4 整除的是闰年
- 整百年份（如 1900 年、2000 年）必须能被 400 整除才是闰年

**参考代码**：

```
year = int(input("请输入年份："))
if (year % 4 == 0 and year % 100 != 0) or (year % 400 == 0):
    print(f"{year}年是闰年")
else:
    print(f"{year}年是平年")
```

#### 1.6 if...elif...else 结构

**场景**：根据用户输入的数字，判断该数字是正数、负数，还是 0。

- 如果数字 > 0：正数
- 如果数字 < 0：负数
- 否则：0

三个互斥的分支，用两个 if...else 嵌套会很啰嗦，于是有了多分支结构。

**语法格式**：

```
if 要判断的条件1:
    条件成立时，执行的操作1
elif 要判断的条件2:
    条件成立时，执行的操作2
else:
    以上条件都不成立时，执行的操作3
```

**执行流程**：

```
开始 → 条件1判断 → True → 操作1
              → False → 条件2判断 → True → 操作2
                                  → False → 操作3
```

**代码示例**：

```
num = int(input("请输入数字："))
if num > 0:
    print(f"{num}是正数")
elif num < 0:
    print(f"{num}是负数")
else:
    print(f"{num}是0")
```

> **注意**：多个分支从上到下依次判断，一旦某个条件成立，就执行对应代码块并跳过整个结构，后面的分支不再判断；只有前面所有条件都不成立，才会继续向下判断，最终都不成立才进入 else。

#### 1.7 if...elif...else 练习

**练习1**：根据输入的用户名、密码进行登录。

- 用户名、密码为 `admin/666888` 或 `root/547527` 或 `zhangsan/123456`，输出登录成功
- 否则提示用户名或密码错误

```
username = input("请输入用户名：")
password = input("请输入密码：")
if (username == "admin" and password == "666888") or

(username == "root" and password == "547527") or

(username == "zhangsan" and password == "123456"):
print("登录成功")
else:
print("用户名或密码错误")
```

> **行尾的 `\` 是什么？** 它是续行符，表示这条语句还没写完，下一行是同一条语句的延续。**更推荐的换行方式是给整个表达式加一对括号，括号内可以直接换行**：
>
> ```
> if ((username == "admin" and password == "666888") or
>     (username == "root" and password == "547527") or
>     (username == "zhangsan" and password == "123456")):
>     print("登录成功")
> ```
>
> 等价的 elif 写法（每组账号密码占一个分支，逻辑更直观）：
>
> ```
> if username == "admin" and password == "666888":
>     print("登录成功")
> elif username == "root" and password == "547527":
>     print("登录成功")
> elif username == "zhangsan" and password == "123456":
>     print("登录成功")
> else:
>     print("用户名或密码错误")
> ```

**练习2**：根据输入的考试成绩，判断成绩等级。

- 大于等于 85 分：优秀
- 60~85 分：及格
- 否则：不及格

```
score = float(input("请输入考试成绩："))
if score >= 85:
    print("优秀")
elif score >= 60:
    print("及格")
else:
    print("不及格")
```

> 注意条件的顺序：先判断大范围（>=85），再判断小范围（>=60）。如果反过来先写 `score >= 60`，85 分会先落入"及格"分支，永远到不了"优秀"。

**练习3**：购物折扣计算：根据输入的购物车商品总额和折扣规则，计算实际应付金额。

- 金额 >= 500：8 折
- 300 <= 金额 < 500：9 折
- 100 <= 金额 < 300：95 折
- 金额 < 100：无折扣

```
total = float(input("请输入购物车商品总额："))
if total >= 500:
    pay = total * 0.8
elif total >= 300:
    pay = total * 0.9
elif total >= 100:
    pay = total * 0.95
else:
    pay = total
print(f"实际应付金额：{pay:.2f}元")
```

> **`{pay:.2f}` 是什么语法？** 这是 f-string 的格式说明符，写在 `{}` 内、冒号后面：`.` 表示保留小数，`2` 表示小数位数，`f` 表示按普通小数（定点数）格式输出，超出位数会自动四舍五入。例如 `f"{3.14159:.2f}"` 输出 `3.14`。处理金额时常用它统一保留两位小数。

#### 1.8 案例：三角形类型判断

**需求**：根据输入的三个边的边长（正整数），判定是等边三角形、等腰三角形、普通三角形，还是不能构成三角形。

**构成三角形的条件**：任意两边之和大于第三边。

**判定规则**：

- 三条边都相等：等边三角形
- 两条边相等：等腰三角形
- 三条边互不相等：普通三角形

**参考代码**：

```
a = int(input("请输入第一条边长："))
b = int(input("请输入第二条边长："))
c = int(input("请输入第三条边长："))
if a + b > c and a + c > b and b + c > a:
    if a == b == c:
        print("等边三角形")
    elif a == b or a == c or b == c:
        print("等腰三角形")
    else:
        print("普通三角形")
else:
    print("不能构成三角形")
```

> **疑问：还需要判断 a - b < c 吗？** 不需要。由 `b + c > a` 可以推出 `a - b < c`，由 `a + c > b` 可以推出 `b - a < c`，两者合起来就是"两边之差的绝对值小于第三边"。所以"任意两边之和大于第三边"与"任意两边之差小于第三边"是等价的条件，写三个"和"的判断就足够了。
>
> 补充：**`a == b == c` 是链式比较，等价于 `a == b and b == c`**。

> **补充：调试技巧**
>
> - 三引号字符串除了定义多行文本，也常当作多行注释使用（写在文件或函数开头时，它就是说明文档 docstring）
> - PyCharm 断点调试：在行号旁单击出现红点即设置断点；右键选择 Debug（或直接点击调试按钮）启动调试。控制台出现"已连接到..."、暂停行的代码高亮，说明已进入调试状态，用工具栏的"步过（Step Over，拐弯箭头）"按钮逐行执行，观察每一步变量的变化

#### 1.9 案例：阶梯电价计算

**需求**：北京市居民年度用电采用阶梯电价计价，根据输入的用电度数计算电费。

- 第一档：2880 度及以下，单价 0.4883 元/度
- 第二档：2880~4800 度，超出第一档部分单价 0.5383 元/度
- 第三档：4800 度以上，超出第二档部分单价 0.7883 元/度

**参考代码**（阶梯计价的核心：每一档只对"超出上一档的部分"按本档单价计费）：

```
degree = float(input("请输入用电度数："))
if degree <= 2880:
    cost = degree * 0.4883
elif degree <= 4800:
    cost = 2880 * 0.4883 + (degree - 2880) * 0.5383
else:
    cost = 2880 * 0.4883 + (4800 - 2880) * 0.5383 + (degree - 4800) * 0.7883
print(f"电费为：{cost:.2f}元")
```

### 二、模式匹配（match...case）

#### 2.1 什么是模式匹配

结构模式匹配是用一个清晰的模板去精准地匹配数据的结构和内容，匹配成功则执行相应的操作。

**版本要求**：Python 3.10 引入的新语法。

#### 2.2 语法格式

```
match 表达式:
    case 值1:
        操作1
    case 值2 if 条件表达式:
        操作2
    case 值3 | 值4:
        操作3
    case _:
        默认操作
```

**说明**：

- `match` 后面跟要匹配的表达式
- `case` 后面跟要匹配的值
- `|` 表示"或"，一个 case 可以匹配多个值中的任意一个
- `case 值 if 条件表达式`：附加条件（守卫），**值为指定值且条件满足时**才匹配
- `case _`：匹配其他所有情况，相当于 else（默认分支）

#### 2.3 执行流程

1. 首先计算 match 后面表达式的值。
2. 从上到下依次与各 case 后面的值匹配，匹配成功就执行对应的语句块。
3. 如果前面所有 case 都没有匹配上，执行默认分支 `case _`。

#### 2.4 案例：工作日程安排

**使用 if...elif...else 实现**：

```
day = input("请输入星期几(1-7)：")
if day == "1":
    print("周一：工作会议日")
elif day == "2":
    print("周二：学习培训日")
elif day == "3":
    print("周三：项目开发日")
elif day == "4":
    print("周四：代码审查日")
elif day == "5":
    print("周五：总结规划日")
elif day == "6" or day == "7":
    print("周末：休息放松")
else:
    print("输入错误")
```

**使用 match...case 实现**：

```
day = input("请输入星期几(1-7)：")
match day:
    case "1":
        print("周一：工作会议日")
    case "2":
        print("周二：学习培训日")
    case "3":
        print("周三：项目开发日")
    case "4":
        print("周四：代码审查日")
    case "5":
        print("周五：总结规划日")
    case "6" | "7":
        print("周末：休息放松")
    case _:
        print("输入错误")
```

> 注意：`input()` 返回字符串，所以 case 匹配的值也要写成字符串 **`"1"`、`"2"`**，而不是数字。

### 三、循环

#### 3.1 while 循环

**循环**：重复地执行某件事情。

**while 循环的语法结构**：

```
while 条件表达式:
    循环体语句1
    循环体语句2
    ...
else:
    循环正常结束时执行的操作   # 可选，可以不写
```

**执行流程**：

```
开始 → 条件表达式判断 → True → 执行循环体 → 回到条件判断
                    → False → 结束
```

> **注意**：while 循环通过条件表达式来控制是否进行下一次循环。

> **else 可以不写吗？** 可以，不写完全没问题，while 单独使用就能完成循环。else 的特殊之处在于：只有循环"正常结束"（条件变为 False）时才执行；**如果循环是被 `break` 跳出的，else 不会执行。因此它常用来区分"循环是跑完了，还是中途被 break 中断了"**。

**代码示例：打印 10 遍"人生苦短，我用Python~"**

```
i = 0
while i < 10:
    print("人生苦短，我用Python~")
    i += 1          # 别忘了更新循环变量，否则 i 永远是 0，条件永远成立（死循环）
else:
    print("循环正常结束，执行完毕")
```

**注意事项**：

1. 条件表达式的结果为**布尔类型**
2. 循环体通过空格缩进表示归属
3. 规划好循环终止的条件**（循环变量要变化），否则会无限循环（死循环）**

#### 3.2 while 循环练习

**需求**：计算 1~100 之间所有偶数的累加之和。

**思考1**：如何获取 1~100 之间的偶数？　**思考2**：累加使用什么运算符？

```
i = 1
total = 0
while i <= 100:
    if i % 2 == 0:      # 偶数才累加
        total += i
    i += 1              # 循环变量必须更新，放在 if 外面，每轮都要执行
print(f"1-100之间所有偶数的累加之和为：{total}")   # 2550
```

> **第一次编写时的三个踩坑点**：
>
> - 忘写 `i += 1`：i 永远是 1，条件一直成立，程序陷入死循环
> - `print(total)` 与 `if` 写在同一缩进层级：print 就归属于 while 循环体，每一轮都会打印一次；求和结果应等循环结束后再输出（print 与 while 对齐）
> - 边界条件写成 `i < 100`：会漏掉 100 这个偶数，结果从 2550 变成 2450；**"1~100 之间（含）"应写 `i <= 100`**
>
> 另外，累加变量不建议命名为 `sum`，它会**覆盖 Python 内置的 `sum()` 函数，推荐用 `total`**。

#### 3.3 for 循环

**for 循环的本质**：一种轮询遍历机制，对一批内容逐个处理。

**执行流程**：

```
开始 → 容器中是否还有元素 → 有 → 取出一个元素 → 处理 → 回到判断
                        → 没有 → 结束
```

**语法格式**：

```
for 元素 in 待处理数据集:
    循环体代码（对元素进行处理）
else:
    循环正常结束时执行的代码   # 可选
```

**代码示例：遍历字符串 "Hello-Python"**

```
# 定义要遍历的字符串
msg = "Hello-Python"
# 遍历字符串，逐个取出字符并处理
for i in msg:
    print(i)
else:
    print("循环结束")
中文字符串同样可以遍历：for 逐个取出的是字符，与字符的语言无关
str1 = "喵而咪之"
for i in str1:
print(i)
```

**小结**：

1. for 循环的语法格式：

   ```
   for 元素 in 待处理数据集:
       循环体代码（对元素进行处理）
   else:
       循环正常结束时执行的操作   # 可选
   ```
2. for 循环与 while 循环的适用场景：

   - **while 循环**：某个条件满足时一直循环，次数通常未知，只知道开始/结束的条件（关注循环条件）
   - **for 循环**：对已知的数据集进行遍历，或已知次数的循环（关注遍历每一个元素）

#### 3.4 range 语句

**作用**：生成指定规则的数字序列（常与 for 循环搭配，提供循环次数）。

| 用法 | 说明 | 示例 |
| --- | --- | --- |
| `range(end)` | 从 0 开始、到 end 结束的数字序列（**不含 end 本身**） | `range(5)` → `0,1,2,3,4` |
| `range(start, end)` | 从 start 开始、到 end 结束的数字序列（不含 end 本身） | `range(2,8)` → `2,3,4,5,6,7` |
| `range(start, end, step)` | 从 start 开始、按步长 step 取值到 end 结束（不含 end 本身） | `range(0,10,2)` → `0,2,4,6,8` |

**代码示例**：

```
for i in range(5):        # 0 1 2 3 4，共循环 5 次
    print(i)
for i in range(1, 10, 2): # 1 3 5 7 9，1~9 之间的奇数
print(i)
```

**小结**：

- `range(...)` 的作用：生成指定规则的数字序列
- 三种用法：`range(end)`、`range(start, end)`、`range(start, end, step)`
- 记住要点：序列**不包含结束值本身**；参数必须是整数

#### 3.5 for 循环练习

**练习1**：计算 1~100 之间所有奇数之和。

```
total = 0
for i in range(1, 101):      # 要取到 100，结束值写 101
    if i % 2 == 1:
        total += i
print(f"1-100之间所有奇数之和为：{total}")   # 2500
```

**练习2**：计算 100~500 之间所有 3 的倍数之和。

```
total = 0
for i in range(100, 501):    # range 不含结束值，要取到 500 就写 501
    if i % 3 == 0:
        total += i
print(f"100-500之间所有3的倍数的数字之和为：{total}")   # 39900
```

> **易错点**：500 虽然不是 3 的倍数，但范围右端点仍要写 501 才严谨覆盖到 500。记住：**range 的结束值不包含在序列内，要取到 N 就写 N+1**。

#### 3.6 嵌套循环

**语法**：

```
for 元素 in 待处理数据集1:      # 外层循环
    for 元素 in 待处理数据集2:  # 内层循环
        循环体代码1
    循环体代码2
```

**案例1：打印长度为 m、宽度为 n 的长方形**

```
m = int(input("请输入长度："))   # 每行星号的个数
n = int(input("请输入宽度："))   # 总行数
for i in range(n):              # 外层循环：控制行数
    for j in range(m):          # 内层循环：控制这一行打印多少个
        print("*", end=" ")     # end=" " 让 print 输出后不换行，星号横向排列
    print()                     # 一行打印完，单独换行
```

> **要点解析**：
>
> - **外层循环控制行数，内层循环控制每行的个数(列数)**——这是所有平面图形打印题的通用思路
> - `print()` 默认输出后自动换行；通过 `end` 参数可以改变结尾内容：`end=" "` 用空格代替换行，让多个输出排在同一行。如果直接 `print("*")`，每个星号都会换行，图形就竖着排列了
> - **`range()` 的参数必须是整数**。如果输入用 `float(input(...))` 转换，再传给 range 会报 `TypeError: 'float' object cannot be interpreted as an integer`，所以行数、列数要用 `int()` 转换
> - **不能直接 `for i in m:`**（m 是整数）。for 遍历的必须是"可迭代对象"（字符串、range 序列、列表等），整数不可迭代，会报 `TypeError: 'int' object is not iterable`。`range(m)` 的作用就是把整数 m 变成可迭代的数字序列
> - 补充技巧：利用字符串乘法可以更简洁地打印一行，如 `print("* " * m)`

**案例2：打印九九乘法表**

```
for i in range(1, 10):                     # 外层：第 1~9 行
    for j in range(1, i + 1):              # 内层：第 i 行有 i 个算式
        print(f"{j} x {i} = {i * j}", end="\t")
    print()                                # 每行结束换行
```

#### 3.7 break 和 continue

| 关键字 | 作用 | 说明 |
| --- | --- | --- |
| `break` | 结束、跳出整个循环 | 不能单独书写，只能出现在循环中 |
| `continue` | 中断本次循环，直接进入下一次循环 | 不能单独书写，只能出现在循环中 |

**代码示例**：

```
for i in range(1, 6):
    if i == 3:
        continue    # 跳过 3，直接进入下一轮循环
    if i == 5:
        break       # 提前结束整个循环，5 不会输出
    print(i)
# 输出：1 2 4
```

**小结**：

- `break`：只能出现在循环中，表示结束、跳出整个循环。
- `continue`：只能出现在循环中，表示中断本次循环，直接进入下一次循环。

#### 3.8 案例：登录系统

**需求**：根据输入的用户名密码执行登录操作：

1. 正确的用户名和密码为 `admin/666888`、`zhangsan/123456`、`taoge/888666`
2. 输入用户名和密码进行登录，直到登录成功程序结束；登录失败则继续输入
3. 输入的用户名和密码不能为空
4. 登录成功：输出"登录成功，进入B站首页~"
5. 登录失败：输出"用户名或密码错误，请重新输入！"

```
while True:                              # 条件恒为 True，配合 break 控制退出
    username = input("请输入用户名：")
    password = input("请输入密码：")
    if username == "" or password == "":
        print("用户名和密码不能为空！")
        continue                         # 放弃本轮，重新输入
    if (username == "admin" and password == "666888") or \
       (username == "zhangsan" and password == "123456") or \
       (username == "taoge" and password == "888666"):
        print("登录成功，进入B站首页~")
        break                            # 登录成功，跳出整个循环
    else:
        print("用户名或密码错误，请重新输入！")
```

**扩展练习**：同上，但只有 5 次登录机会，连续输错 5 次后不允许再操作。

```
count = 0
while count < 5:
    username = input("请输入用户名：")
    password = input("请输入密码：")
    if (username == "admin" and password == "666888") or \
       (username == "zhangsan" and password == "123456") or \
       (username == "taoge" and password == "888666"):
