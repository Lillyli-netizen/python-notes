<br><p><strong>场景</strong>：只有满足指定条件，才会执行对应的代码逻辑。</p> <br><p><strong>语法格式</strong>：</p> <br><pre><code class="language-python">if 要判断的条件:<br>    条件成立时，要执行的操作1<br>    条件成立时，要执行的操作2<br></code></pre> <br><p><strong>代码示例</strong>：</p> <br><pre><code class="language-python"># input() 返回字符串，参与数值比较前先转成 int<br>score = int(input("请输入成绩："))<br># 如果分数超过 680，输出欢迎信息<br>if score >= 680:<br>    print("欢迎你，来清华读书")<br>    print("也恭喜你即将踏入精彩的大学生活")<br></code></pre> <br><blockquote> <br> <p><strong>如果把 if 代码块里的某一行再多缩进一层会怎样？</strong></p> <br> <pre><code class="language-python">if score > 680:<br>    print("欢迎你，来清华读书")<br>        print("也恭喜你即将踏入精彩的大学生活")   # 报错：IndentationError: unexpected indent<br></code></pre> <br> <p>Python 通过缩进判断代码归属。多缩进一层意味着"开启了新的子代码块"，而<strong>开启新代码块必须由 <code>if</code>、<code>for</code>、<code>while</code>、<code>def</code> 等复合语句引导</strong>；普通语句后面跟着更深缩进的代码，解释器无法确定它属于谁，就会报 <code>IndentationError: unexpected indent</code>。所以同一代码块内的语句必须保持相同的缩进。</p> 通过缩进来描述代码的层级关系（归属）；在 PyCharm 中按 Tab 键会自动转为空格</li></ol> <br><p></p> <br><h4 id="1.2%20%E6%A1%88%E4%BE%8B%EF%BC%9AB%E7%AB%99%E7%99%BB%E5%BD%95" 操作1<br>              → False → 操作2<br></code></pre> <br><p><strong>代码示例</strong>：</p> <br><pre><code class="language-python">score = 695<br>if score > 680:<br>    print("欢迎你，来清华读书")<br>else:<br>    print("继续努力，再接再厉")<br></code></pre> <br><p><strong>注意事项</strong>：</p> <br><ol><li><code>else</code> 不需要写条件，当 if 条件不成立时，自动执行 else 代码块</li><li>else 及其代码块同样需要缩进（建议 4 个空格）</li></ol> <br><p></p> <br><h4 print(f"{num}是负数")<br></code></pre> <br><p><strong>需求4</strong>：根据用户输入的考试分数，判断是否及格（大于等于 60 即及格）。</p> <br><pre><code class="language-python">score = float(input("请输入考试分数："))<br>if score >= 60:<br>    print("及格了")<br>else:<br>    print("不及格")<br></code></pre> <br><h4 id="1.5%20%E6%A1%88%E4%BE%8B%EF%BC%9A%E5%88%A4%E6%96%AD%E9%97%B0%E5%B9%B4"
