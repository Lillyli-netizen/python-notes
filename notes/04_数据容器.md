name="%E4%B8%80%E3%80%81%E6%95%B0%E6%8D%AE%E5%AE%B9%E5%99%A8%E6%A6%82%E8%BF%B0">一、数据容器概述</h3> <br><h4 id="1.1%20%E4%BB%80%E4%B9%88%E6%98%AF%E6%95%B0%E6%8D%AE%E5%AE%B9%E5%99%A8" name="1.1%20%E4%BB%80%E4%B9%88%E6%98%AF%E6%95%B0%E6%8D%AE%E5%AE%B9%E5%99%A8">1.1 什么是数据容器</h4> <br><p><strong>数据容器</strong>：一种可以容纳多份数据的数据类型，容纳的每一份数据称为一个元素，每一个元素都可以是任意类型的数据（如字符串、数字、布尔等）。</p> <br><p><strong>为什么需要数据容器？</strong></p> <br><p>当需要存储多个数据时，如果每个数据都定义为一个独立变量，代码会非常繁琐：</p> <br><pre><code class="language-python"># 繁琐的写法<br>score1 = 695<br>score2 = 558<br>score3 = 622<br>score4 = 589<br>score5 = 645<br># ... 更多变量<br>优雅的写法（数据容器）<br>score_list = [695, 558, 622, 589, 645, 607, 577, 552, 475, 602]</code></pre> <br><h4 id="1.2%20%E4%BA%94%E5%A4%A7%E6%A0%B8%E5%BF%83%E6%95%B0%E6%8D%AE%E5%AE%B9%E5%99%A8" name="1.2%20%E4%BA%94%E5%A4%A7%E6%A0%B8%E5%BF%83%E6%95%B0%E6%8D%AE%E5%AE%B9%E5%99%A8">1.2 五大核心数据容器</h4> <br><table><thead><tr><th>容器类型</th><th>英文</th><th>特点</th></tr></thead><tbody><tr><td>列表</td><td><code>list</code></td><td>有序、可重复、可修改</td></tr><tr><td>字符串</td><td><code>str</code></td><td>有序、可重复、不可修改</td></tr><tr><td>元组</td><td><code>tuple</code></td><td>有序、可重复、不可修改</td></tr><tr><td>集合</td><td><code>set</code></td><td>无序、不可重复、可修改</td></tr><tr><td>字典</td><td><code>dict</code></td><td>键值对存储、key 不可重复、可修改</td></tr></tbody></table> <br><p><strong>核心对比维度</strong>：</p> <br><ol><li>是否支持重复元素</li><li>是否可以修改</li><li>是否有序</li></ol> <br><h3 id="%E4%BA%8C%E3%80%81%E5%88%97%E8%A1%A8%EF%BC%88list%EF%BC%89" name="%E4%BA%8C%E3%80%81%E5%88%97%E8%A1%A8%EF%BC%88list%EF%BC%89">二、列表（list）</h3> <br><h4 id="2.1%20%E5%88%97%E8%A1%A8%E4%BB%8B%E7%BB%8D" name="2.1%20%E5%88%97%E8%A1%A8%E4%BB%8B%E7%BB%8D">2.1 列表介绍</h4> <br><p><strong>列表</strong>是数据容器中的一类，一次性可以存储多个数据（元素）。</p> <br><p><strong>定义</strong>：</p> <br><pre><code class="language-python">列表名称 = [元素1, 元素2, 元素3, 元素4, 元素5, ...]<br></code></pre> <br><p><strong>代码示例</strong>：</p> <br><pre><code class="language-python">s = [54, 15, 75, 108, 23, 78, 75]<br></code></pre> <br><p><strong>特点</strong>：</p> <br><ul><li>可以存储不同类型的元素</li><li>元素<strong>有序</strong>、<strong>可以重复</strong>、<strong>可以修改</strong></li></ul> <br><h4 id="2.2%20%E5%88%97%E8%A1%A8%E7%9A%84%E7%B4%A2%E5%BC%95" name="2.2%20%E5%88%97%E8%A1%A8%E7%9A%84%E7%B4%A2%E5%BC%95">2.2 列表的索引</h4> <br><p><strong>序列类型</strong>：元素按特定顺序排列、可以通过索引访问的容器类型，称为序列。</p> <br><p><strong>索引规则</strong>：</p> <br><ul><li><strong>正向索引</strong>：从前向后，下标从 <strong>0</strong> 开始</li><li><strong>反向索引</strong>：从后向前，下标从 <strong>-1</strong> 开始</li></ul> <br><p><strong>代码示例</strong>：</p> <br><pre><code class="language-python">s = [54, 15, 75, 108, 23, 78, 75]<br>#    0   1   2    3   4   5   6   （正向索引）<br>#   -7  -6  -5   -4  -3  -2  -1   （反向索引）<br>print(s[0])     # 54（用中括号 + 索引获取元素）<br>print(s[1])     # 15<br>print(s[6])     # 75<br>print(s[-1])    # 75<br>print(s[-7])    # 54<br>修改<br>s[0] = "A"<br>print(s)        # ['A', 15, 75, 108, 23, 78, 75]<br>删除<br>del s[3]<br>print(s)        # ['A', 15, 75, 23, 78, 75]<br>用 for 循环遍历取出每个元素<br>for i in s:<br>print(i)</code></pre> <br><blockquote> <br> <p><strong>注意</strong>：指定的索引超出范围会报错（<code>IndexError: list index out of range</code>）。</p> <br></blockquote> <br><p><strong>小结</strong>：</p> <br><ol><li>列表的定义与特点：<code>列表名 = [元素1, 元素2, 元素3]</code>；可存放不同类型元素、可重复、有序、可修改</li><li>列表的索引：正向索引从 0 开始，反向索引从 -1 开始</li><li>元素操作：查看 <code>list1[0]</code>、修改 <code>list1[0] = "A"</code>、删除 <code>del list1[3]</code></li></ol> <br><h4 id="2.3%20%E5%88%97%E8%A1%A8%E7%9A%84%E5%88%87%E7%89%87" name="2.3%20%E5%88%97%E8%A1%A8%E7%9A%84%E5%88%87%E7%89%87">2.3 列表的切片</h4> <br><p><strong>介绍</strong>：切片是指从操作的数据中截取一部分的操作。列表、字符串、元组都支持切片。</p> <br><p><strong>语法</strong>：</p> <br><pre><code class="language-python">序列数据[开始索引:结束索引:步长]<br></code></pre> <br><p><strong>要点</strong>：</p> <br><ul><li><strong>不包含结束索引位置对应的元素</strong></li><li>开始索引不指定，默认为 0</li><li>结束索引不指定，默认为列表长度（取到末尾）</li><li>步长不指定，默认为 1</li><li>正向、反向索引都可以使用</li><li>步长是选取间隔，为负数时表示从后往前取</li></ul> <br><p><strong>代码示例</strong>：</p> <br><pre><code class="language-python">s = ["A", "C", "E", "B", "D", "E", "G"]<br>print(s[0:5:1])   # ['A', 'C', 'E', 'B', 'D']<br>print(s[0:5:2])   # ['A', 'E', 'D']        步长 2：隔一个取一个<br>print(s[:3])      # ['A', 'C', 'E']        start 省略，默认 0<br>print(s[3:])      # ['B', 'D', 'E', 'G']   end 省略，默认取到末尾<br>print(s[::2])     # ['A', 'E', 'D', 'G']<br>print(s[::-1])    # ['G', 'E', 'D', 'B', 'E', 'C', 'A']   步长 -1：反转<br></code></pre> <br><blockquote> <br> <p><strong><code>s[::-1]</code> 为什么能反转？</strong><br /> 步长表示"每次移动几步、朝哪个方向走"。步长为负数表示从后往前取；start 和 end 都省略、步长为 -1 时，含义就是"从最后一个元素一直取到第一个元素"，恰好把整个序列倒过来。<code>[::-1]</code> 可以作为"反转序列"的固定写法记住。</p> <br> <p><strong>切片表达式不写 print 为什么看不到结果？</strong><br /> 在 Python Console（交互式环境）中，单独写一个表达式（如 <code>s[0:3]</code>）会自动回显结果；但在 <code>.py</code> 脚本文件里，表达式的结果必须用 <code>print()</code> 输出，否则计算完就被丢弃，什么也看不到。另外，<code>s[:3:]</code> 与 <code>s[:3]</code> 等价（末尾单独的冒号省略了步长 1），习惯写 <code>s[:3]</code> 即可。</p> <br></blockquote> <br><p><strong>小结</strong>：</p> <br><ul><li>语法：<code>s[start:end:step]</code></li><li><code>start</code>：开始索引，不指定默认为 0</li><li><code>end</code>：结束索引，不指定默认为列表长度（不含 end （反向索引）<br>print(s[0])     # P<br>print(s[5])     # n<br>print(s[-1])    # n<br>print(s[-6])    # P<br></code></pre> <br><h4 id="3.2%20%E5%AD%97%E7%AC%A6%E4%B8%B2%E7%9A%84%E5%88%87%E7%89%87" print("不是回文")<br></code></pre> <br><blockquote> <br> <p><strong>为什么"反转后比较"就能判断回文？</strong></p> <br> <p>回文的定义是：正着读和反着读完全一样（如 <code>level</code>、<code>上海自来水来自海上</code>）。<code>s[::-1]</code> 得到 s 字符串标识符.upper()</code>。</li></ul> <br></blockquote> <br><h3 id="%E5%9B%9B%E3%80%81%E5%85%83%E7%BB%84%EF%BC%88tuple%EF%BC%89" <br><ul><li>可以存储不同类型的元素</li><li>元素<strong>可以重复</strong>、<strong>有序</strong>、<strong>不可以修改</strong>（支持索引访问、切片）</li></ul> <br><p><strong>定义</strong>：</p> <br><pre><code class="language-python"># <br><ol><li>元组的特点：元素可以重复、有序、不可修改（只读）</li><li>两个查询方法：<code>count()</code> 统计指定元素的数量；<code>index()</code> 获取指定元素的索引，元素不存在会报错</li><li>注意事项：定义单元素元组时结尾必须加逗号，如 <code>('A',)</code></li></ol> <br><h4 <br><p><strong>组包（Packing）</strong>：将多个值合并到一个容器（元组、列表）中。</p> <br><p><strong>解包（Unpacking）</strong>：将容器解开成独立的元素，分别赋值给多个变量。</p> <br><pre><code class="language-python"># 定义元组，本身就是组包<br>t1 = (5, 7, 9,              # [5, 7, 9]<br>print(e)                 # 1</code></pre> <br><p><strong>小结</strong>：</p> <br><ul><li><strong>组包</strong>：多个值合并进一个容器；<strong>解包</strong>：容器元素分别赋给多个变量</li><li><code>*</code> 元组案例：变量交换</h4> <br><p><strong>案例1</strong>：两个变量 <code>a = 10</code>、<code>b = 20</code>，交换值并输出。</p> <br><pre><code class="language-python">a = 10<br>b = 20<br>a, b = b, a   # 右边先把 b, a 组包成元组 (20,
