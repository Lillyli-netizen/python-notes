### 一、Python 初识

#### 1.1 Python 的起源

- Python 由荷兰计算机科学家 吉多·范罗苏姆 （Guido van Rossum，昵称“龟叔”）创造，他于 1989 年 开始编写， 1991 年发布第一个版本 。
- 特点：语法简单、容易上手，应用领域非常广泛。

#### 1.2 语言与编程语言

- **语言**：人类进行沟通交流的主要表达方式。
- **编程语言**：人类与计算机之间进行信息交流的一种特殊语言。
- 计算机只能识别二进制指令（0 和 1），因此需要 **解释器** 把编程语言翻译成计算机可执行的机器码。

#### 1.3 Python 的应用范围

根据 TIOBE 编程社区指数（2025 年 10 月数据），Python 排名第一，占比 24.45%，且持续上升。

| 序号 | 应用领域 | 说明 |
| --- | --- | --- |
| 1 | 教育/竞赛 | Python 课程、计算机二级、ACM 竞赛等 |
| 2 | 办公自动化 | Excel、Word、PDF 等文档处理 |
| 3 | 网络爬虫 | 数据采集程序开发 |
| 4 | Web 开发 | 网站服务端程序开发 |
| 5 | 数据分析/可视化 | 图表制作、数据探索 |
| 6 | 大数据/分布式计算 | 大数据开发、分布式计算 |
| 7 | 自动化测试/运维 | 测试开发、运维开发 |
| 8 | AI/机器学习/深度学习 | 大模型开发、机器学习、深度学习等 |

> **总结**：Python 是一门语法简洁、容易上手、应用广泛的编程语言。

### 二、Python 环境准备

#### 2.1 Python 解释器安装

- **官网**：[https://www.python.org](https://www.python.org/ "https://www.python.org")
- **下载步骤**：
  1. 访问官网，点击 Downloads；
  2. 选择对应操作系统（如 Windows）；
  3. 下载最新版本（如 Python 3.14.0）；
  4. 运行安装程序，**务必勾选 “Add python.exe to PATH”**（将 Python 添加到环境变量）；
  5. 选择安装路径（建议安装在无中文、无空格的目录下）。
- **验证安装**：
  1. 按 `Win + R`，输入 `cmd`，打开命令提示符。
  2. 输入 `python` 并回车，若出现 Python 版本信息及 `>>>` 提示符，则安装成功。
  3. 输入 `exit()` 可退出交互环境。

#### 2.2 常见问题及解决方案

##### 问题 1：输入 `python` 提示“不是内部或外部命令”

- **原因**：未将 Python 添加到系统环境变量 Path 中。
- **解决方案**：
  1. 重新安装 Python，勾选 “Add python.exe to PATH”。
  2. 手动配置环境变量：

     - 右键“此电脑” → 属性 → 高级系统设置 → 环境变量。
     - 或手动配置环境变量：右键“此电脑” → 属性 → 高级系统设置 → 环境变量，在 Path 中添加 Python 安装目录及`Scripts` 目录（如`D:\develop\python\` 和`D:\develop\python\Scripts\` ），确定保存后重新打开命令提示符。

##### 问题 2：输入 `python` 打开了 Microsoft Store

- **原因**：Windows 系统的“应用执行别名”干扰。
- **解决方案**：
  - 设置 → 应用 → 高级应用设置 → 应用执行别名 → 关闭python.exe 和python3.exe 的别名；或使用完整路径运行 Python。

#### 2.3 Path 环境变量的作用

- **作用**：告诉操作系统，在命令行输入命令时应到哪些目录中查找对应的可执行程序。
- **工作流程**：
  1. 用户输入命令；
  2. 系统先判断是否为内部命令；
  3. 若不是，则依次到 Path 指定的目录中查找；
  4. 找到则执行，找不到则报错：“不是内部或外部命令，也不是可运行的程序或批处理文件。”
- **用户变量 vs 系统变量**：
  - **用户变量**：仅对当前登录用户有效。
  - **系统变量**：对所有用户有效。

### 三、Python 开发工具

#### 3.1 常见开发工具

- **VSCode**：轻量级编辑器，插件生态丰富，支持多种语言。
- **PyCharm**：JetBrains 公司出品的专业 Python IDE，Python 开发中使用最广泛。

#### 3.2 脱离开发工具运行 Python（古法编程 了解即可）

只用解释器也能运行 Python，过程如下：

1. **交互模式**：在 cmd 中输入 `python` 进入 `>>>` 环境，但每次只能执行**一行**代码，编写多行程序很不方便。
2. **脚本文件**：Python 是**脚本语言**，代码可以写在文本文件中，由解释器从上到下逐行执行——用记事本写好多行代码，把后缀名改为 `.py` 即可。
3. **运行脚本**：在 cmd 中执行 `python 文件名.py`。若提示找不到文件，有两种解决方法：
   - **方法一**：用 `cd` 命令切换到文件所在目录后再运行。
   - **方法二**：在文件资源管理器中打开文件所在文件夹，在地址栏输入 `cmd` 回车，可直接在该目录下打开命令提示符。
4. **显示文件扩展名**：系统默认隐藏扩展名，需在资源管理器中勾选“查看 → 显示 → 文件扩展名”，才能确认后缀已改为 `.py`。
5. **查看系统类型**：设置 → 系统 → 系统信息 → 系统类型（如 64 位操作系统），用于选择匹配的安装包。

**结论**：以上方式都只依赖解释器，缺少代码提示、错误提示、一键运行等功能，因此实际开发中引入**开发工具（IDE）**。

#### 3.3 PyCharm 简介与下载

- **官网**：[PyCharm: The only Python IDE you need](https://www.jetbrains.com/pycharm/ "PyCharm: The only Python IDE you need")
- **下载**：选择 Windows 版本，下载 `.exe` 安装包。

#### 3.4 PyCharm 基本配置

- **主题颜色**：设置 → 外观与行为 → 外观 → 主题（Light/Dark）。
- **字体设置**：设置 → 编辑器 → 字体，可调整字体类型、大小、行高。
- **推荐字体**：Microsoft YaHei UI，大小 12。

### 四、Python 入门程序

#### 4.1 创建项目与文件

1. 打开 PyCharm，点击“新建项目”。
2. 设置项目位置（无中文、无空格路径）和项目名称。
3. 选择解释器类型：项目 venv（虚拟环境），基础解释器选择已安装的 Python。
4. 点击“创建”。
5. 在项目中右键 → New → Python File，命名为 `01. 快速入门.py`。

#### 4.2 编写第一个 Python 程序

```
# 输出 Hello World
print("Hello World")
print("Hello Python")
```

- **运行方式**
- 右键 → Run '01. 快速入门'。
- 或使用快捷键 `Shift + F10`。

- **注意事项**：

  ```
  <ul>
  ```
- 所有符号必须使用**英文符号，**中文符号会直接导致语法错误；
- Python 使用**换行**作为语句结束标志，一行写一条语句；也可用分号`;` 分隔多条语句（不推荐）；
- 源文件后缀名为`.py` 。

> 技巧（输入法标点设置） ：在中文输入法中开启“**中文状态下使用英文标点**”，避免反复切换。
>
> 以微软拼音为例：设置 → 常规 → 标点，选择“半角”；也可用`Ctrl + .` 快捷键临时切换中英文标点。

#### 4.3 注释

- **作用**：对代码进行解释说明，供开发人员阅读，Python 解释器会忽略注释内容。
- **单行注释**：以 `#` 开头。

  ```
  # 这是一个单行注释
  print("Hello")
  ```
- **快捷键**：`Ctrl + /`（可批量注释/取消注释）。

#### 4.4 项目目录结构

一个典型的 PyCharm 项目目录如下：

```
项目名/
├── .idea/          # 项目配置信息，由 PyCharm 自动生成并管理
├── .venv/          # 虚拟环境，保存本项目专属的依赖包
└── 01.快速入门.py   # Python 源代码文件
```

- **虚拟环境（.venv）**：让每个项目在独立的隔离环境中运行，可针对单个项目安装依赖，项目之间互不影响。
- **注意** ：`.idea/` 和`.venv/` 由工具自动生成和维护，项目创建后不要手动改动。

#### 4.5 PyCharm 常用配置

- **主题**：设置 → 外观与行为 → 外观 → 主题。
- **字体**：设置 → 编辑器 → 字体 → 字体、大小、行高。
- **编码**：确保文件编码为 UTF-8。

### 五、小结与练习

#### 5.1 小结

- - Python 源文件后缀名为`.py` 。
- 单行注释以`#` 开头，快捷键为`Ctrl + /` 。
- 所有符号必须使用英文符号（可设置输入法“中文时用英文标点”）。
- 一行一条语句，以换行结束；分号不推荐。
- 交互模式一次只能执行一行，`.py` 脚本文件由解释器逐行执行。
- 虚拟环境`.venv` 用于隔离项目依赖。

#### 5.2 练习

**需求**：在控制台按以下形式输出古诗《登鹳雀楼》（共 6 行）：

```
# # # # # #
#白日依山尽#
#黄河入海流#
#欲穷千里目#
#更上一层楼#
# # # # # #
```

```
print("# # # # # #")

print("#更上一层楼#")
```
