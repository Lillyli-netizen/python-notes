<br><table><thead><tr><th>类型</th><th>标准名称</th><th>描述</th><th>示例</th></tr></thead><tbody><tr><td>整数</td><td><code>int</code></td><td>数字类型，存放整数</td><td><code>10</code>、<code>18</code>、<code>-5</code>、<code>0</code></td></tr><tr><td>浮点数</td><td><code>float</code></td><td>数字类型，存放小数</td><td><code>8.5</code>、<code>3.14</code>、<code>1.0</code>、<code>-3.5</code></td></tr><tr><td>布尔</td><td><code>bool</code></td><td>表示逻辑上的真或假</td><td><code>True</code>、<code>False</code></td></tr><tr><td>字符串</td><td><code>str</code></td><td>描述文本的数据类型</td><td><code>"人生苦短，我用Python"</code></td></tr><tr><td>空值</td><td><code>NoneType</code></td><td>表示空或无值，仅包含一个值 <br><pre><code class="language-python">print(100)            # 整数（int）<br>print(3.14)           # 浮点数（float）<br>print(True)           # 布尔（bool），首字母必须大写<br>print("hello world")  # <code>True</code> / <code>False</code>；空值写 <code>None</code>。</li></ol> <br><h4 id="1.2%20%E5%8F%98%E9%87%8F" name="1.2%20%E5%8F%98%E9%87%8F">1.2 变量</h4> <br><p><strong>变量</strong>：程序中用来存储数据的容器。经常变化或需要重复使用的数据，通常存放在变量中。</p> <br><p><strong>定义格式</strong>：</p> <br><pre><code class="language-python">变量名 = 变量值<br></code></pre> <br><p><strong>格式说明</strong>：</p> <br><ul><li><strong>变量名</strong>：给存储数据的空间起的名字</li><li><strong><code>=</code></strong>：赋值运算符，把等号右侧的值赋予左侧的变量</li><li><strong>变量值</strong>：变量中存储的具体数据</li></ul> <br><p><strong>代码示例（动态类型）</strong>：</p> <br><pre><code class="language-python"># Python 是动态类型语言：同一个变量可以先后绑定不同类型的数据<br># （但项目开发中，推荐一个变量只存储一种类型的数据）<br>num = 1114.1<br>print(num)       # 1114.1<br>num = num + 1    # 用变量的旧值参与运算，再把结果赋回变量<br>print(num)       # 1115.1<br>num = 'ok'       # 变量重新绑定到字符串<br>print(num)       # ok<br>num = True       # 变量重新绑定到布尔值<br>print(num)       # True</code></pre> <br><blockquote> <br> <p><strong>为什么 <code>print()</code> 输出的是值，而不是内存地址？</strong><br /> Python 的变量本质是"名字 → 对象"的绑定关系，变量里保存的确实是对象的引用（可理解为地址）。但 <code>print()</code> 的设计目标就是给人看的，<strong>它会自动把对象当前的内容转换成可读文本输出，所以看到的是"值"而不是地址</strong>——这与 C、Java 等语言打印对象默认输出地址的习惯不同，是 Python 有意的设计。如果确实想查看对象的内存地址，可以使用内置函数 <code>id(变量)</code>。</p> <br></blockquote> <br><p><strong>一条语句定义多个变量</strong>：左右两侧用逗号分隔，按位置一一对应赋值：</p> <br><pre><code class="language-python">a, b = 1, "Python"   # a = 1，b = "Python"<br>numBase, incr = 20.7, 50<br></code></pre> <br><p><strong>输出变量的常用方式</strong>（以"字符串 + 数字"混合输出为例）：</p> <br><pre><code class="language-python">numBase = 20.7<br>incr = 50<br>方式一：print 多参数输出，逗号分隔，各部分之间自动加一个空格<br>print("未来第一个月的播放量:", numBase + incr)<br>方式二：f-string 格式化（推荐），变量直接嵌入字符串<br>print(f"未来第一个月的播放量: {numBase + incr}")<br>方式三：字符串拼接，非字符串必须先用 str() 转换<br>print("未来第一个月的播放量: " + str(numBase + incr))</code></pre> <br><p><strong>案例：B站课程播放量</strong></p> <br><p>需求：课程基础播放量为 20.7 万，每月新增播放量 50 万，输出未来两个月每个月的播放总量。</p> <br><pre><code class="language-python">base = 20.7    # 基础播放量（万）<br>add = 50       # 每月新增播放量（万）<br>month1 = base + add        # 第一个月：基础 + 新增<br>month2 = month1 + add      # 第二个月：第一个月 + 新增<br>print(f"第一个月播放总量：{month1}万")   # 第一个月播放总量：70.7万<br>print(f"第二个月播放总量：{month2}万")   # 第二个月播放总量：120.7万</code></pre> <br><p><strong>小结</strong>：</p> <br><ol><li>变量是存储数据的容器，定义格式：<code>变量名 = 变量值</code>。</li><li>变量的用途：输出打印、参与计算、记录数据。</li><li>注意事项： <br>  <ul><li>一个变量同一时刻只存储一个值，重复赋值会覆盖旧值</li><li>变量必须先赋值（定义）才能使用</li><li>一条语句可以定义多个变量：<code>a, b = 1, "Python"</code></li></ul> </li></ol> <br><h4 id="1.3%20%E6%A0%87%E8%AF%86%E7%AC%A6" id="2.5.1%20%E4%BD%BF%E7%94%A8%20%25%20%E5%8D%A0%E4%BD%8D%E7%AC%A6" name="2.5.1%20%E4%BD%BF%E7%94%A8%20%25%20%E5%8D%A0%E4%BD%8D%E7%AC%A6">2.5.1 使用 <code>%</code> 占位符</h5> <br><p><strong>记忆方法</strong>：把 <code>%s</code> 读作"这里留一个空位"。<code>%</code> 表示占位，<code>s</code> 表示把填入的数据先转成字符串（s = string）再放到这个位置。</p> <br><p>好处：因为会自动转成字符串，所以<strong>任何类型的数据</strong>都能填入 "人生苦短"<br>s2 = "我用Python"<br>print(f"吉多·范罗苏姆：{s1}，{s2}")</code></pre> <br><p><strong>小结</strong>：</p> <br><ol><li>字符串拼接：使用 <code>+</code> 号；不能直接拼接非字符串，其他类型需先 <code>str(...)</code> 转换。</li><li><code>%</code> 格式化：<code>"%s" % 变量</code> / <code>"%s…%s" % (变量1, 变量2)</code>，任意类型自动转字符串。</li><li>f-string 格式化（推荐）：<code>f"内容{变量/表达式}"</code>。</li></ol> <br><h3 <br><h4 id="4.2%20%E8%B5%8B%E5%80%BC%E8%BF%90%E7%AE%97%E7%AC%A6" name="4.2%20%E8%B5%8B%E5%80%BC%E8%BF%90%E7%AE%97%E7%AC%A6">4.2 赋值运算符</h4> <br><p>赋值运算符用于把右侧的值（或表达式的结果）保存到左侧的变量中。</p> 逻辑运算符</h4> <br><p>逻辑运算符用于连接多个布尔表达式（其值为"真"或"假"），并返回一个最终的布尔结果。</p> <br><table><thead><tr><th>运算符</th><th>描述</th><th>说明</th></tr></thead><tbody><tr><td><code>and</code></td><td>逻辑与（并且）</td><td>左右两边都为
