模块（Module）</strong>：一个 <code>.py</code> 文件就是一个模块，模块是 Python 程序的基本组织单位。在模块中可以定义变量、函数、类，以及可执行的代码。</p> <br><p><strong>示例</strong>：<code>circle_fun.py</code> 就是一个模块，其中定义了计算圆面积和周长的函数。</p> <br><pre><code <br><h4>1.3 模块的作用</h4> <br><ol><li><strong>提高代码复用性</strong>：将通用功能封装为模块，多处调用</li><li><strong>降低开发门槛</strong>：使用现成模块，无需重复造轮子</li><li><strong>避免命名冲突</strong>：不同模块中的同名变量/函数互不影响</li></ol> <br><p><strong>小结</strong>：</p> <br><ol><li>什么是模块？有什么用？ <br>  <ul><li>模块：一个 Python 文件（<code>.py</code>），其中包含变量、函数、类，以及可执行的代码</li><li>作用：提高代码复用性，降低开发门槛，避免命名冲突</li></ul> </li><li>导入模块的常用语法？ <br>  <ul><li><code>import 模块名 [as 别名]</code></li><li><code>from 模块名 import 功能名 [as 别名]</code></li><li><code>from 模块名 import *</code></li></ul> </li></ol> <br><h3>二、模块导入方式</h3> <code>rd</code>，不能用 <code>random</code>）。</p> <br></blockquote> <br><p><strong>（3）<code>from 模块名 import 功能名</code></strong></p> <br><pre><code class="language-python">from random import randint, <br><p><strong>示例</strong>：将一个大型项目拆分为多个模块文件</p> <br><pre><code class="language-python">项目/<br>├── config.py          # 配置模块<br>├── session.py         # 会话管理模块<br>├── ai_partner.py      # 主程序模块<br>└── 基础配置项（常量：不会发生变化的数据，命名全部大写）<br>PAGE_TITLE = "AI 树洞"                       # 页面标题<br>PAGE_ICON = "🌳"                             # 页面 icon<br>LAYOUT = "wide"                              # 中非常重要的内置变量，表示<strong>当前模块的名称</strong>。</p> <br><table><thead><tr><th>场景</th><th><code>__name__</code> 的值</th></tr></thead><tbody><tr><td><strong>模块直接运行时</strong>（<code>python my_fun.py</code>）</td><td><code>"__main__"</code></td></tr><tr><td><strong>模块被导入时</strong>（<code>import my_fun</code>）</td><td>模块的文件名（不含 <code>.py</code> 后缀），如 <code>"my_fun"</code></td></tr></tbody></table> <br><blockquote> <br> <p><strong>注意拼写</strong>：判断语句必须写 <code>if __name__ == "__main__":</code>——两侧都是<strong>双下划线</strong>。写成 <code>'_main_'</code>（单下划线）条件永远不成立，测试代码不会被执行。</p> <br></blockquote> <br><p><strong>为什么需要它？（详细过程）</strong></p> <br><p><code>if __name__ == "__main__":</code> 里的代码叫<strong>测试代码</strong>（只在直接运行本模块时才需要执行的代码）。它的执行逻辑是：</p> <br><pre><code class="language-python"># my_fun.py<br>PI = 3.1415926<br><br>def log_separator1():<br>    print("-" * 30)<br><br>def log_separator2():<br>    print("+ " * 30)<br><br># 测试代码：写在本模块 if 判断之下<br>if __name__ == "__main__":<br>    log_separator1()    # 直接运行 my_fun.py 时会执行；被导入时不会执行<br></code></pre> <br><ol><li><strong>直接运行</strong> <code>python my_fun.py</code>：此时 Python 把 my_fun 当作<strong>主程序</strong>，<code>__name__</code> 的值为 <code>"__main__"</code>，条件成立 → 测试代码执行（如打印一条分隔线，方便自测函数）。</li><li><strong>被其他文件导入</strong> <code>import my_fun</code>：此时 <code>__name__</code> 的值为 <code>"my_fun"</code>，条件不成立 → 测试代码<strong>跳过</strong>，但函数定义照常加载，供导入方调用。</li><li><strong>好处</strong>：一个文件既可以作为程序直接运行（跑测试），又可以作为模块被导入（只提供功能、不执行测试），互不干扰。</li></ol> <br><blockquote> <br> <p><strong>PyCharm 小技巧</strong>：在函数体（if 判断）之外输入 <code>main</code> 后按 Tab，可快速补全 <code>if __name__ == "__main__":</code> 模板；</p> <br> <p><code>Ctrl + Y</code> 可快速删除当前行。另外，<code>def log_separator4(): print("* " * 30)</code> 写在同一行虽然语法允许，但不符合规范，建议换行缩进。</p> <br></blockquote> <br><p><strong>典型用法</strong>：</p> <br><pre><code class="language-python"># my_module.py<br>def main():<br>    print("执行主逻辑")<br><br>if __name__ == "__main__":<br>    main()<br></code></pre> <br><blockquote> <br> <p><strong>说明</strong>：<code>if __name__ == "__main__":</code> 用于判断当前模块是作为主程序直接运行，还是被其他模块导入。</p> <br></blockquote> <br><h4>3.3 <code>__all__</code> 特殊变量</h4> <br><p><code>__all__</code> 是一个模块级别的特殊变量，用于指定 <code>from 模块名 import *</code> 时会导入哪些功能（<code>*</code> 通配了哪些功能）。</p> <br><p><strong>示例</strong>：</p> <br><p><strong>my.py</strong>：</p> <br><pre><code class="language-python"># 只有用列表中的名字写了 __all__，import * 时才会被导入<br>__all__ = ["log_separator1", "log_separator3", "PI"]<br><br>PI = 3.1415926<br>NAME = "lulu"<br><br>def log_separator1():<br>    print("- " * 30)<br><br>def log_separator2():<br>    print("+ " * 30)<br><br>def log_separator3():<br>    print("# " * 30)<br><br>def log_separator4():<br>    print("* " * 30)<br></code></pre> <br><p><strong>test.py</strong>：</p> <br><pre><code class="language-python">from my import *<br><br>log_separator1()    # ✅ 正常调用（在 __all__ 中）<br>log_separator3()    # ✅ 正常调用（在 __all__ 中）<br>print(PI)           # ✅ 正常访问（在 __all__ 中）<br><br>log_separator2()    # ❌ NameError：不在 __all__ 中，import * 没有导入它<br>log_separator4()    # ❌ NameError：同上<br>print(NAME)         # ❌ NameError：同上<br></code></pre> <br><blockquote> <br> <p><strong>"<code>__all__</code> 并不会影响直接导入具体的功能"是什么意思？</strong></p> <br> <p><code>__all__</code> <strong>只对 <code>from 模块名 import *</code> 这一种写法生效</strong>。如果导入时明确写出功能名，就不受 <code>__all__</code> 限制：</p> <br> <pre><code class="language-python">from my import log_separator2, NAME<br><br>log_separator2()    # ✅ 完全可以调用<br>print(NAME)         # ✅ 完全可以访问<br></code></pre> <br> <p><code>__all__</code> 是给 <code>import *</code> 划的"白名单"——它不删除、不隐藏模块里的任何功能，只决定"批量全拿"时拿哪些。想用白名单之外的功能，指名道姓地导入即可。</p> <br></blockquote> <br><p><strong>小结</strong>：</p> <br><ol><li><code>__name__</code> 与 <code>__all__</code> 的作用： <br>  <ul><li><code>__name__</code>：内置变量，表示当前模块的名称；直接运行时为 <code>"__main__"</code>，被导入时为模块文件名（不含 <code>.py</code>）</li><li><code>__all__</code>：控制 <code>from 模块名 import *</code> 时导入哪些功能（不影响指名导入）</li></ul> </li></ol> <br><h3>四、软件包（Package）</h3> <br><h4>4.1 什么是包</h4> <br><p><strong>包</strong>：本质是一个文件夹，其中可以包含若干 Python 模块（<code>.py</code> 文件），并且文件夹下包含一个 <code>__init__.py</code> 文件。</p> <br><p><strong>作用</strong>：模块文件较多时，用来管理、归类多个模块。（包的本质也是一个模块）</p> <br><p><strong>包的结构示例</strong>：</p> <br><pre><code class="language-python">utils/<br>├── __init__.py       # 包的初始化文件（描述当前包的信息）<br>├── my_fun.py         # 功能模块<br>├── my_var.py         # 变量模块<br>└── my_config.py      # 配置模块<br></code></pre> <br><p><strong>创建包的两种方式</strong>：</p> <br><ol><li>手动创建：新建一个普通文件夹，在文件夹下新建 <code>__init__.py</code> 文件，该文件夹即成为软件包</li><li>PyCharm 创建：右键项目 → <code>New</code> → <code>Python Package</code>，输入英文包名（如 <code>utils</code>），PyCharm 会自动创建文件夹并带上 <code>__init__.py</code>（推荐）</li></ol> <br><p><strong><code>__init__.py</code> 的作用</strong>：</p> <br><ol><li>标识这是一个包，而不是普通的文件夹</li><li>可以编写包的描述信息（版本号、作者等）</li><li>通过 <code>__all__</code> 变量控制 <code>from 包名 import *</code> 时导入的模块列表</li></ol> <br><p><strong><code>__init__.py</code> 示例</strong>：</p> <br><pre><code class="language-python"># utils/__init__.py<br><br># 包的描述信息<br>__version__ = "1.0.0"<br>__author__ = "lili"<br><br># 控制 from utils import * 时导入的模块<br>__all__ = ["my_fun", "my_var"]<br></code></pre> <br><h4>4.2 包的导入方式</h4> <br><table><thead><tr><th>导入形式</th><th>代码样例</th><th>调用方式</th></tr></thead><tbody><tr><td><code>import 包名.模块名</code></td><td><code>import utils.my_fun</code></td><td><code>包名.模块名.功能名</code> → <code>utils.my_fun.log_separator1()</code></td></tr><tr><td><code>from 包名 import 模块名</code></td><td><code>from utils import my_fun</code></td><td><code>模块名.功能名</code> → <code>my_fun.log_separator1()</code></td></tr><tr><td><code>from 包名 import *</code></td><td><code>from utils import *</code></td><td><code>模块名.功能名</code> → <code>my_fun.log_separator1()</code></td></tr><tr><td><code>from 包名.模块名 import 功能名</code></td><td><code>from utils.my_fun import log_separator1</code></td><td><code>功能名</code> → <code>log_separator1()</code></td></tr><tr><td><code>from 包名.模块名 import *</code></td><td><code>from utils.my_fun import *</code></td><td><code>功能名</code> → <code>log_separator1()</code></td></tr></tbody></table> <br><p><strong>各导入方式详解</strong>（设 <code>utils/my_fun.py</code> 中定义了 <code>log_separator1</code> ~ <code>log_separator4</code> 等功能）：</p> <br><p><strong>（1）<code>import 包名.模块名</code></strong></p> <br><pre><code class="language-python">import utils.my_fun<br><br>utils.my_fun.log_separator1()<br></code></pre> <br><p><strong>（2）<code>from 包名 import 模块名</code></strong></p> <br><pre><code class="language-python">from utils import my_fun<br><br>my_fun.log_separator1()<br></code></pre> <br><p><strong>（3）<code>from 包名 import *</code></strong></p> <br><pre><code class="language-python">from utils import *<br><br>my_fun.log_separator1()    # 能导入哪些模块，受 __init__.py 中 __all__ 的控制<br></code></pre> <br><p><strong>（4）<code>from 包名.模块名 import 功能名</code></strong></p> <br><pre><code class="language-python">from utils.my_fun import log_separator1<br><br>log_separator1()<br></code></pre> <br><p><strong>（5）<code>from 包名.模块名 import *</code></strong></p> <br><pre><code class="language-python">from utils.my_fun import *<br><br>log_separator1()           # 受 my_fun.py 中 __all__ 的控制<br></code></pre> <br><blockquote> <br> <p><strong>补充：绝对导入与相对导入</strong></p> <br> <p>上面的写法都是<strong>绝对导入</strong>：从项目根目录的包开始，写出完整路径（如 <code>from utils.my_fun import ...</code>）。</p> <br> <p><strong>相对导入</strong>则用 <code>.</code>（当前包）和 <code>..</code>（上一级包）描述位置，写在<strong>包内部的模块</strong>中，用于包内模块之间互相导入：</p> <br> <pre><code class="language-python"># utils/my_var.py 中需要用到同包的 my_fun<br>from . import my_fun           # . 表示当前包（utils）<br>from .my_fun import log_separator1    # 从当前包的 my_fun 模块导入功能<br><br># 如果是包中包（utils/sub/my.py），从上一级包导入：<br>from .. import my_var          # .. 表示上一级包（utils）<br></code></pre> <br> <p>绝对导入像"从项目根开始的完整地址"，相对导入像"以我为中心的相对位置"。注意：包含相对导入的模块<strong>不能直接运行</strong>（<code>python my_var.py</code> 会报 <code>ImportError: attempted relative import with no known parent package</code>），它只能被导入使用。</p> <br></blockquote> <br><p><strong>小结</strong>：</p> <br><ol><li>什么是包？有什么作用？ <br>  <ul><li>包就是一个文件夹，里面可以存储很多 Python 模块（<code>.py</code> 文件），通过包可以对模块进行归类管理</li></ul> </li><li><code>__init__.py</code> 文件的作用？ <br>  <ul><li>标识这是一个包，而不是普通的文件夹</li><li>可以编写包的描述信息（版本、作者等）</li><li>通过 <code>__all__</code> 控制 <code>from 包名 import *</code> 时导入的模块列表</li></ul> </li><li>导入包的方式？ <br>  <ul><li><code>import 包名.模块名</code></li><li><code>from 包名 import 模块名</code></li><li><code>from 包名 import *</code></li><li><code>from 包名.模块名 import 功能名</code></li><li><code>from 包名.模块名 import *</code></li></ul> </li><li>补充：导入路径分<strong>绝对导入</strong>（完整路径）与<strong>相对导入</strong>（<code>.</code> 当前包、<code>..</code> 上一级包），相对导入只能用于包内部模块之间。</li></ol>
