### 一、模块概述

#### 1.1 什么是模块

**Python 模块（Module）**：一个 `.py` 文件就是一个模块，模块是 Python 程序的基本组织单位。在模块中可以定义变量、函数、类，以及可执行的代码。

**示例**：`circle_fun.py` 就是一个模块，其中定义了计算圆面积和周长的函数。

```
# circle_fun.py 模块文件

# 根据半径计算圆的面积
def circle_area(r):
    pi = 3.14
    area = pi * r * r
    return area

# 根据半径计算圆的周长
def circle_len(r):
    pi = 3.14
    length = 2 * pi * r
    return length
```

```
# main.py 主程序文件

# 从自定义模块 circle_fun 中导入需要的函数
from circle_fun import circle_area

print("=== 披萨成本计算 ===")
# 披萨尺寸（半径，厘米）
s_radius = 10    # 小号披萨
m_radius = 15    # 中号披萨
l_radius = 20    # 大号披萨

# 计算面积
small_area = circle_area(s_radius)
medium_area = circle_area(m_radius)
large_area = circle_area(l_radius)

# 成本计算（面饼+配料：0.05元/平方厘米）
small_cost = small_area * 0.05
medium_cost = medium_area * 0.05
large_cost = large_area * 0.05

print(f"小号披萨成本：{small_cost:.2f}元")
print(f"中号披萨成本：{medium_cost:.2f}元")
print(f"大号披萨成本：{large_cost:.2f}元")
```

#### 1.2 模块的分类

| 分类 | 说明 | 示例 |
| --- | --- | --- |
| **内置模块** | Python 自带的模块 | `math`（数学计算）、`random`（随机数）、`os`（操作系统）、`sys`（系统参数）、`datetime`（日期时间）、`time`（时间访问）、`re`（正则）、`csv`（CSV 文件操作） |
| **自定义模块** | 开发者自己编写的 `.py` 文件 | 如 `circle_fun.py`、`config.py`、`session.py` |

#### 1.3 模块的作用

1. **提高代码复用性**：将通用功能封装为模块，多处调用
2. **降低开发门槛**：使用现成模块，无需重复造轮子
3. **避免命名冲突**：不同模块中的同名变量/函数互不影响

**小结**：

1. 什么是模块？有什么用？
   - 模块：一个 Python 文件（`.py`），其中包含变量、函数、类，以及可执行的代码
   - 作用：提高代码复用性，降低开发门槛，避免命名冲突
2. 导入模块的常用语法？
   - `import 模块名 [as 别名]`
   - `from 模块名 import 功能名 [as 别名]`
   - `from 模块名 import *`

### 二、模块导入方式

使用模块中提供的功能之前，必须**先导入，再使用**，导入语句一般放在文件开头。

#### 2.1 导入方式一览

| 导入形式 | 代码样例 | 调用方式 |
| --- | --- | --- |
| `import 模块名` | `import random` | `模块名.功能名` → `random.randint(1, 100)` |
| `import 模块名 as 别名` | `import random as rd` | `别名.功能名` → `rd.randint(1, 100)` |
| `from 模块名 import 功能名` | `from random import randint` | `功能名` → `randint(1, 100)` |
| `from 模块名 import 功能名 as 别名` | `from random import randint as rint` | `别名` → `rint(1, 100)` |
| `from 模块名 import *` | `from random import *` | `功能名` → `randint(1, 100)` |

#### 2.2 各导入方式详解

**（1）`import 模块名`**

```
import random

# randint(1, 100)：生成 1~100 之间的随机整数（包含 1 和 100 两端）
num = random.randint(1, 100)
print(num)
```

> 调用时需使用 `模块名.功能名` 的形式。

**（2）`import 模块名 as 别名`**

```
import random as rd

num = rd.randint(1, 100)
print(num)
```

> 适用于模块名较长，或避免命名冲突时。注意：起了别名后，原名不能再使用（只能用 `rd`，不能用 `random`）。

**（3）`from 模块名 import 功能名`**

```
from random import randint, choice

num = randint(1, 100)
print(num)

item = choice(["A", "B", "C"])
print(item)
```

> 直接使用功能名调用，无需加模块名前缀。

**（4）`from 模块名 import 功能名 as 别名`**

```
from random import randint as rint

num = rint(1, 100)
print(num)
```

**（5）`from 模块名 import *`**

```
from random import *

num = randint(1, 100)
print(num)
```

> 导入模块中的所有功能（受模块内 `__all__` 变量的控制，见 3.3）。

**课堂练习：三种写法各打印 10 个随机数**

```
# 方式一：import 模块名
import random
for i in range(10):
    print(random.randint(1, 100))    # 包含 1 和 100 两端

# 方式二/三：from 导入具体功能 或 功能别名
from random import randint
from random import randint as rint

for i in range(10):
    # print(randint(1, 100))
    print(rint(1, 100))
```

### 三、自定义模块

#### 3.1 什么是自定义模块

开发复杂项目时，为了让项目结构更清晰、便于维护管理和代码复用，可以把项目拆分为若干个模块。

**示例**：将一个大型项目拆分为多个模块文件

```
项目/
├── config.py          # 配置模块
├── session.py         # 会话管理模块
├── ai_partner.py      # 主程序模块
└── utils/             # 工具包
    ├── my_fun.py
    ├── my_var.py
    └── my_config.py
```

**config.py**（配置模块）：

```
# 基础配置项（常量：不会发生变化的数据，命名全部大写）
PAGE_TITLE = "AI 树洞"                       # 页面标题
PAGE_ICON = "🌳"                             # 页面 icon
LAYOUT = "wide"                              # 页面布局
INITIAL_SIDEBAR_STATE = "expanded"           # 侧边栏初始状态
HELP_URL = "https://www.itheima.com/help"    # 帮助地址
SESSION_LOCATION = "sessions/"               # 会话数据存储位置
```

**session.py**（会话管理模块）：

```
import os
import streamlit as st    # st 是第三方库 streamlit 的引用，此处仅作示例

# 加载会话列表
def load_session():
    sessions = []
    if os.path.exists("sessions"):
        for filename in os.listdir("sessions"):
            if filename.endswith(".json"):
                sessions.append(filename[:-5])    # 去掉 .json 后缀作为会话名
    return sorted(sessions, reverse=True)

# 保存当前会话
def save_session(session_name):
    if session_name:
        session_data = {
            "messages": st.session_state.messages,
            "name": st.session_state.session_name,
            "temperature": st.session_state.temperature,
            "model": st.session_state.model,
        }
        # ... 保存逻辑
```

**ai\_partner.py**（主程序模块）：

```
# 导入自定义模块
from session import load_session, save_session

# 新建会话按钮
if st.button("新建会话", icon="💬", use_container_width=True):
    # 保存当前会话（如果有）
    if st.session_state.current_session:
        save_session(st.session_state.current_session)
    # 创建新会话
    new_session_name = generate_new_session_name()
    st.session_state.current_session = new_session_name
    st.session_state.messages = []
    save_session(new_session_name)
    st.session_state.sessions = load_session()
    st.rerun()
```

> **注意**：每一个 Python 文件都可以作为一个模块，模块名就是文件名（建议用合法的 Python 标识符规范命名，不要用中文、空格或与内置模块重名）。

#### 3.2 `__name__` 特殊变量

`__name__` 是 Python 中非常重要的内置变量，表示**当前模块的名称**。

| 场景 | `__name__` 的值 |
| --- | --- |
| **模块直接运行时**（`python my_fun.py`） | `"__main__"` |
| **模块被导入时**（`import my_fun`） | 模块的文件名（不含 `.py` 后缀），如 `"my_fun"` |

> **注意拼写**：判断语句必须写 `if __name__ == "__main__":`——两侧都是**双下划线**。写成 `'_main_'`（单下划线）条件永远不成立，测试代码不会被执行。

**为什么需要它？（详细过程）**

`if __name__ == "__main__":` 里的代码叫**测试代码**（只在直接运行本模块时才需要执行的代码）。它的执行逻辑是：

```
# my_fun.py
PI = 3.1415926

def log_separator1():
    print("-" * 30)

def log_separator2():
    print("+ " * 30)

# 测试代码：写在本模块 if 判断之下
if __name__ == "__main__":
    log_separator1()    # 直接运行 my_fun.py 时会执行；被导入时不会执行
```

1. **直接运行** `python my_fun.py`：此时 Python 把 my\_fun 当作**主程序**，`__name__` 的值为 `"__main__"`，条件成立 → 测试代码执行（如打印一条分隔线，方便自测函数）。
2. **被其他文件导入** `import my_fun`：此时 `__name__` 的值为 `"my_fun"`，条件不成立 → 测试代码**跳过**，但函数定义照常加载，供导入方调用。
3. **好处**：一个文件既可以作为程序直接运行（跑测试），又可以作为模块被导入（只提供功能、不执行测试），互不干扰。

> **PyCharm 小技巧**：在函数体（if 判断）之外输入 `main` 后按 Tab，可快速补全 `if __name__ == "__main__":` 模板；
>
> `Ctrl + Y` 可快速删除当前行。另外，`def log_separator4(): print("* " * 30)` 写在同一行虽然语法允许，但不符合规范，建议换行缩进。

**典型用法**：

```
# my_module.py
def main():
    print("执行主逻辑")

if __name__ == "__main__":
    main()
```

> **说明**：`if __name__ == "__main__":` 用于判断当前模块是作为主程序直接运行，还是被其他模块导入。

#### 3.3 `__all__` 特殊变量

`__all__` 是一个模块级别的特殊变量，用于指定 `from 模块名 import *` 时会导入哪些功能（`*` 通配了哪些功能）。

**示例**：

**my.py**：

```
# 只有用列表中的名字写了 __all__，import * 时才会被导入
__all__ = ["log_separator1", "log_separator3", "PI"]

PI = 3.1415926
NAME = "lulu"

def log_separator1():
    print("- " * 30)

def log_separator2():
    print("+ " * 30)

def log_separator3():
    print("# " * 30)

def log_separator4():
    print("* " * 30)
```

**test.py**：

```
from my import *

log_separator1()    # ✅ 正常调用（在 __all__ 中）
log_separator3()    # ✅ 正常调用（在 __all__ 中）
print(PI)           # ✅ 正常访问（在 __all__ 中）

log_separator2()    # ❌ NameError：不在 __all__ 中，import * 没有导入它
log_separator4()    # ❌ NameError：同上
print(NAME)         # ❌ NameError：同上
```

> **"`__all__` 并不会影响直接导入具体的功能"是什么意思？**
>
> `__all__` **只对 `from 模块名 import *` 这一种写法生效**。如果导入时明确写出功能名，就不受 `__all__` 限制：
>
> ```
> from my import log_separator2, NAME
>
> log_separator2()    # ✅ 完全可以调用
> print(NAME)         # ✅ 完全可以访问
> ```
>
> `__all__` 是给 `import *` 划的"白名单"——它不删除、不隐藏模块里的任何功能，只决定"批量全拿"时拿哪些。想用白名单之外的功能，指名道姓地导入即可。

**小结**：

1. `__name__` 与 `__all__` 的作用：
   - `__name__`：内置变量，表示当前模块的名称；直接运行时为 `"__main__"`，被导入时为模块文件名（不含 `.py`）
   - `__all__`：控制 `from 模块名 import *` 时导入哪些功能（不影响指名导入）

### 四、软件包（Package）

#### 4.1 什么是包

**包**：本质是一个文件夹，其中可以包含若干 Python 模块（`.py` 文件），并且文件夹下包含一个 `__init__.py` 文件。

**作用**：模块文件较多时，用来管理、归类多个模块。（包的本质也是一个模块）

**包的结构示例**：

```
utils/
├── __init__.py       # 包的初始化文件（描述当前包的信息）
├── my_fun.py         # 功能模块
├── my_var.py         # 变量模块
└── my_config.py      # 配置模块
```

**创建包的两种方式**：

1. 手动创建：新建一个普通文件夹，在文件夹下新建 `__init__.py` 文件，该文件夹即成为软件包
2. PyCharm 创建：右键项目 → `New` → `Python Package`，输入英文包名（如 `utils`），PyCharm 会自动创建文件夹并带上 `__init__.py`（推荐）

**`__init__.py` 的作用**：

1. 标识这是一个包，而不是普通的文件夹
2. 可以编写包的描述信息（版本号、作者等）
3. 通过 `__all__` 变量控制 `from 包名 import *` 时导入的模块列表

**`__init__.py` 示例**：

```
# utils/__init__.py

# 包的描述信息
__version__ = "1.0.0"
__author__ = "lili"

# 控制 from utils import * 时导入的模块
__all__ = ["my_fun", "my_var"]
```

#### 4.2 包的导入方式

| 导入形式 | 代码样例 | 调用方式 |
| --- | --- | --- |
| `import 包名.模块名` | `import utils.my_fun` | `包名.模块名.功能名` → `utils.my_fun.log_separator1()` |
| `from 包名 import 模块名` | `from utils import my_fun` | `模块名.功能名` → `my_fun.log_separator1()` |
| `from 包名 import *` | `from utils import *` | `模块名.功能名` → `my_fun.log_separator1()` |
| `from 包名.模块名 import 功能名` | `from utils.my_fun import log_separator1` | `功能名` → `log_separator1()` |
| `from 包名.模块名 import *` | `from utils.my_fun import *` | `功能名` → `log_separator1()` |

**各导入方式详解**（设 `utils/my_fun.py` 中定义了 `log_separator1` ~ `log_separator4` 等功能）：

**（1）`import 包名.模块名`**

```
import utils.my_fun

utils.my_fun.log_separator1()
```

**（2）`from 包名 import 模块名`**

```
from utils import my_fun

my_fun.log_separator1()
```

**（3）`from 包名 import *`**

```
from utils import *

my_fun.log_separator1()    # 能导入哪些模块，受 __init__.py 中 __all__ 的控制
```

**（4）`from 包名.模块名 import 功能名`**

```
from utils.my_fun import log_separator1

log_separator1()
```

**（5）`from 包名.模块名 import *`**

```
from utils.my_fun import *

log_separator1()           # 受 my_fun.py 中 __all__ 的控制
```

> **补充：绝对导入与相对导入**
>
> 上面的写法都是**绝对导入**：从项目根目录的包开始，写出完整路径（如 `from utils.my_fun import ...`）。
>
> **相对导入**则用 `.`（当前包）和 `..`（上一级包）描述位置，写在**包内部的模块**中，用于包内模块之间互相导入：
>
> ```
> # utils/my_var.py 中需要用到同包的 my_fun
> from . import my_fun           # . 表示当前包（utils）
> from .my_fun import log_separator1    # 从当前包的 my_fun 模块导入功能
>
> # 如果是包中包（utils/sub/my.py），从上一级包导入：
> from .. import my_var          # .. 表示上一级包（utils）
> ```
>
> 绝对导入像"从项目根开始的完整地址"，相对导入像"以我为中心的相对位置"。注意：包含相对导入的模块**不能直接运行**（`python my_var.py` 会报 `ImportError: attempted relative import with no known parent package`），它只能被导入使用。

**小结**：

1. 什么是包？有什么作用？
   - 包就是一个文件夹，里面可以存储很多 Python 模块（`.py` 文件），通过包可以对模块进行归类管理
2. `__init__.py` 文件的作用？
   - 标识这是一个包，而不是普通的文件夹
   - 可以编写包的描述信息（版本、作者等）
   - 通过 `__all__` 控制 `from 包名 import *` 时导入的模块列表
3. 导入包的方式？
   - `import 包名.模块名`
   - `from 包名 import 模块名`
   - `from 包名 import *`
   - `from 包名.模块名 import 功能名`
   - `from 包名.模块名 import *`
4. 补充：导入路径分**绝对导入**（完整路径）与**相对导入**（`.` 当前包、`..` 上一级包），相对导入只能用于包内部模块之间。
